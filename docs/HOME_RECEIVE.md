## 다음 내보내기를 연결하는 방법

1333의 히스토리에서 등록 항목을 아래 순서로 두고 새 Excel 문서를 생성한다.

`현재가 / 누적거래량 / 누적거래대금 / 시가총액 / 기관순매수금액 / 외국인순매수금액`

단일 시트, 세로, 내림차순, 각 종목 날짜, 거래일만 포함, 종가, 실시간 갱신 해제 설정을 유지한다. 새 날짜 폴더에 XLSX를 저장한다. 기존 설정 `private_data/infomax/home-20260928/daily-config.json`은 세 종목의 식별정보와 기존 사용자 정책을 포함한다. 종목이 바뀌면 이름·분류를 실제 입력과 대조해 별도 설정한다.

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/infomax_daily.py --input <새-XLSX> --config <이-PC-설정-JSON> --as-of <조회종료일-YYYY-MM-DD> --output <새-스냅샷-JSON>
.\.venv\Scripts\python.exe -X utf8 batch.py import-file --profile home --mode user_input --file <새-스냅샷-JSON>
```

변환기는 당일 제외, 과거 결측·중복·미래 날짜·필드 순서·종목코드·종목 간 날짜 일치를 검사한다. 잘못된 입력에서 과거 날짜를 더 끌어와 기간을 바꾸지 않는다. 출력 파일은 새 이름이어야 한다. SQLite 적재 후 브라우저를 새로고침한다. Excel 조회와 저장은 여전히 명시적 실행 단계이며 예약 작업은 없다.
