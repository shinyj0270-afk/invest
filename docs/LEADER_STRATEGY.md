# 주도주 전략 화면 (2026-10-19 작업 워크트리 구현)

사용자 결정(2026-10-19): SK증권 「[퀀트전략] 이길 수 없다면 합류하라」(2025-04-30, 황지우 — 작성자는 사용자 제공 정보)의 모멘텀·거래대금·밸류 분류를 대시보드의 **주요 전략**으로 받아들인다. 새 '주도주 전략' 화면에 분류·후보까지 먼저 구현하고 HRP 비중은 다음 단계로 분리한다. 구현 순서는 산업별 국면 확산(docs/INDUSTRY_DASHBOARD.md "다음 개발") 다음이다. 공개 원문 URL을 확인하지 못해 Research Library에는 등록하지 않았고, 화면 설명에는 "SK증권 2025-04-30 보고서(사용자 제공 자료, 공개 URL 미확인)"로 표기한다. 원문은 사용자 PC의 투입 폴더에만 있다.

## 보고서 전략 요약 (작성자 요약, 원문 복제 아님)

- 2020년 이후 개인투자자·MTS·ETF 확대로 군집행동이 강해져 국내에도 단기 모멘텀이 관찰된다는 주장.
- 종목을 수익률(모멘텀)과 거래대금 변화로 각 3단계, 3×3=9칸으로 분류하고, 밸류 종합점수 3단계를 더해 27칸으로 나눈다.
- 보고서 표본에서 단순 주도주보다 "주도 + 밸류 중립"의 샤프비율·MDD가 나았다고 집계(보고서 집계, 우리 자료로 재현 전).
- 같은 테마 종목의 동조를 줄이려 HRP 비중을 쓰고, 시장 위험은 TIPS·가치주 등으로 헤지한다(이번 범위 제외).

## 화면

- 새 화면 '주도주 전략'(추세추종과 같은 묶음): 시장 선택, 9칸 분포표(칸 클릭 → 해당 종목), 밸류 3단계 전환, "주도+밸류 중립" 후보 목록(기업 분석 연결), 산업별 후보 분포(산업 연구 화면 연결), 정의·출처·보고서와 차이 패널.
- 관측값 배지, 투자 판단·매수 추천 아님. 보고서 성과 수치는 "보고서 집계"로 구분.
- 회사 결과 조회(정적 공유)에도 공개 기업 관측값만 포함한다. 원문 PDF·연구 DB는 넣지 않는다.

## 검증 계획

- 단위: VWAP·거래대금 경계(이력 부족, 0 거래량, 정지), 극단값 대체, z 경계(±1.5 포함 여부), 밸류 지표 결측·음수 PER 제외, 시장 분리.
- 화면: 1440/390/320px, XSS, 빈 칸·결측, 결과 조회 화면. 격리 UI 검사 포함.
- 실제 자료: 분포가 한쪽으로 몰리지 않는지(±1.5σ에서 칸별 기업 수) 확인 후 기준값 재검토를 사용자에게 제시.

## 다음 단계(별도 결정)

HRP 참고 비중(기존 포트폴리오 모델은 변경하지 않음), 칸 명칭 확정, 우리 저장 이력으로 27칸 사후 성과 집계.

## 구현 세부와 검증

`investment/leader_strategy.py`가 기존 완료 가격 검증과 재무 공통 계산을 읽고, `src/leader_strategy_ui.js`가 저장된 결과만 표시한다. 탐색 묶음의 **주도주 전략**과 모바일 페이지 선택에서 연다. `config/leader_strategy.json`에 기준을 고정했다. 원지표÷규모 보정은 추가 질문에 답변이 오기 전 공개한 구현 기본값이며 사용자 확정 결정과 구분한다.

거래대금 원값이 두 비교 구간 모두 확보되면 사용한다. 하나라도 없으면 두 구간 모두 조정종가×거래량 근사로 통일하고 화면에 표시한다. 실제 체결 VWAP·거래대금의 재현은 아니다. 비교 구간의 0·미확보 거래량, 거래정지, 가격일 불일치는 제외한다. 최근 21일과 정확히 252관측일 이전의 21일 비교에는 최소 273관측일이 필요하다.

시장별 표본 5개 미만 또는 상수 분포이면 좌표 미확인이다. 동일 시총은 보정값 1이다. 밸류는 검증된 기존 지표만 읽고, 시장·재무 기간·연결/별도·통화·가격일이 같은 집합끼리 양수 지표를 역백분위로 바꾼다. 동률은 중간순위이고, 각 지표와 최종 종합 비교 집합 모두 최소 5개를 요구한다. 음수·0 PER은 제외하고 다른 양수 지표가 2개 이상 확보되면 사용한다. 기준이 다른 지표를 섞거나 결측을 중립으로 대체하지 않는다. 개별 재무의 추정 주식수·공식 원문 우선 계산 경계는 기존 `common_metrics`를 따른다.

검사: `python -m unittest tests.test_industry_phase tests.test_leader_strategy`, `python tests/test_strategy_views_ui.py`. 계산 경계·실제 거래대금/근사 전환·시장 분리·규모 보정 순서·상수 분포·XSS·정적/결과 화면 외부 요청 0·1440/390/320px와 기업/산업 연결을 확인한다. 공유 후보 격리 검증에도 포함했다. 저장 자료의 9칸·가치 분포와 한계는 [관측 점검](STRATEGY_OBSERVATION_CHECK.md)에 기록한다.
