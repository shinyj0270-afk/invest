# 시장 자금 흐름

통합 대시보드 홈의 **시장 자금 흐름 → 수급 보기**에서 열고 **수급 갱신**으로 공개 자료를 조회한다. 주식 스냅샷이 없는 새 PC에서는 자료 대기 화면의 링크로도 열 수 있다. 읽기 전용 실행과 휴대폰은 저장 자료를 조회한다.

국내 화면은 외국인 또는 기관을 골라 KODEX 200·KODEX 반도체와 국고채 3년·10년 ETF의 장내 순매매를 비교한다. 삼성전자와 SK하이닉스의 직접 매매는 반도체 ETF 해석을 보조한다. 단위는 각 종목의 주식·ETF 수량이다. 금액 환산이나 서로 다른 주식·좌수의 합산은 하지 않는다. 출처는 네이버 투자자별 매매동향이다. 조회 당일을 제외한 최근 최대 40개 원천 관측으로 3·5·20일을 계산한다.

- 3일 초기 관측은 같은 주체가 양쪽을 반대로 거래한 날이 2일 이상이고, 양쪽 3일 누적 순매수/누적거래량이 서로 반대 부호로 각각 절댓값 1% 이상인 경우다.
- 지속은 초기 조건에 같은 방향의 5일 비율 조건과 동시 매매 3일 이상이 더해진 경우다. 반대 방향도 같은 조건을 적용한다. 결측·거래량 0은 보류한다. 최근 신호 이력은 현재 조회한 원천을 날짜별로 재계산한 관측이다. 최초 공개 빈티지를 복원한 성과검증이 아니다.
- 20일 종가 변화는 20개 가격 간격으로 계산하며 분배금·권리변동을 반영하지 않는다. 기준일이 직전 평일과 다르면 휴일 가능성을 포함한 지연 표기를 한다.
- 선물·장외채권·ETF 설정과 환매는 국내 표본에 포함되지 않는다. 투자자 유형 안에서 계좌별 거래의 연결 여부는 알 수 없다. 임계값과 적중률은 별도 검증 대상이다.

미국 주간 수급은 ICI의 Combined Estimated Long-Term Flows and ETF Net Issuance 공식 발표 중 Equity와 Bond 행을 사용한다. 관측 주 마감과 발표일을 함께 표시하고 백만 달러를 100으로 나누어 억 달러로 표시한다. 출처별 성공분만 .local/market-flows에 원자적으로 저장하며 조회·검증 실패, 날짜 후퇴 시 이전 정상 자료를 유지한다. 원자료·로컬 캐시는 Git 공유 대상에서 제외한다. [ICI 주간 원문](https://www.ici.org/research/stats/combined_flows)

PC에서 ICI 자동 조회를 제한하면 원문 주간 표를 복사해 UTF-8 탭 구분 파일로 저장한다. 첫 행은 빈 셀 뒤 최신순 M/D/YYYY 날짜, Equity 및 Bond 행은 부호 있는 백만 달러 금액이다. 아래 날짜는 발표일 예시다.

```powershell
python tools/market_flows.py --ici-table weekly.tsv --published 2026-11-04
python tools/market_flows.py --refresh
python tools/market_flows.py --html market-flows.html
```

HTML 내보내기는 해당 시점의 관측을 담는다. 화면에서 수급을 갱신하려면 로컬 대시보드로 연다.
