# 대시보드 고도화 기준 · 2026-10-02

## 화면과 자료

- 메인 화면에 재무 저장/연속 TTM/ROE 계산 가능 기업 수, 공통 관측일 가격 수, KOSPI·KOSDAQ의 시장 환경을 추가했다. 기업별 재무와 차트는 선택할 때 조회하는 구조를 유지한다.
- 검색·간단 분석의 공통 재무 기준은 연결(CFS) 최신 저장 단독분기다. 영업이익률은 분기 영업이익/매출, 매출 성장률은 전년 같은 분기 대비, 부채비율은 연결 부채/자본이다.
- ROE는 연속 4분기 지배순이익/전년 동기와 현재 평균 지배자본. 연결 지배주주 계정이 없으면 전체 순이익으로 대체하지 않는다. 분기 공백·누락 계정은 0 대신 —로 표시한다. 표의 금액 단위는 억원이다.
- 인포맥스 검토 지표는 **같은 연결/기간**, 평가비율은 같은 가격일까지 맞는 경우 우선한다. 다른 기간의 기존 검색 수치를 최신 상세 재무에 혼합하지 않는다. 원금액의 1억원 미만 차이는 기존 정책대로 오차 경고에서 제외한다.
- PER/PBR은 확인된 지배주주 분모와 완료 종가를 사용한다. 공식 보통주식수 대신 최근 제공 시총/가격으로 주식수를 추정한 경우 근사로 표시한다. 가격일까지 3일을 초과하거나 자료가 없으면 계산하지 않는다. 과거 권리변동/주식수 불변 가정의 한계가 있다.
- 재무 수집은 기존 분기 정기 업데이트와 일간 공시 모니터를 사용한다. 새 분기는 반영하고 같은 기간 정정은 누적 7% 이상, 0/부호 변화일 때 반영한다. 미확보·실패를 수집 성공으로 바꾸지 않는다.

## 장후 일봉·가격 대조

- 앱을 열 때와 열어둔 동안 자동으로 가격 갱신 상태를 확인한다. 실제 조회 시도는 30분 간격으로 제한한다. 앱을 닫았을 때의 예약 실행은 없다.
- 일반 완료 일봉은 전날까지, 한국시간 평일 18:30 이후 자동 갱신은 당일까지 요청한다. 제공자 일봉 날짜와 KOSPI/KOSDAQ 공통 관측일, 종목별 기준을 검증한다. 종목 실패 수와 기존 자료 보존을 상태에 표시한다. 메인에 완료 관측 날짜를 노출하고, 7달력일을 넘은 기준은 오래된 자료로 표시한다(휴장일 판정과 별도).
- 18:30은 제공자 게시 지연과 지연 개장을 감안한 **자체 수집 버퍼**이며 공식 거래소 확정 표시나 모든 시장의 거래 종료 시각이 아니다. 휴장/원천 게시 지연은 최근 실제 관측일을 유지하고 다음 조회에서 재확인한다. [KRX 거래시간](https://global.krx.co.kr/contents/GLB/06/0602/0602020204/GLB0602020204T1.jsp).
- 새로고침 버튼은 최신 제공 가격을 별도로 조회한다. 시세 지연 여부·시장·제공 시각 미확인이면 표시를 보존하고 장후 완료 종가를 자동 대체하지 않는다.
- 추세 화면의 ‘가격 출처·시장·수정 기준 대조’에서 저장 검토 이력과 네이버 차트의 같은 날짜 가격 차이를 확인한다. 시장/권리변동 기준이 둘 다 확인되고 같을 때만 직접 비교 가능하다. 미확인은 ‘기준 대조 필요’. 차이를 이유로 원가격을 자동 수정하지 않는다. 스탁이지 원천 시세 공급계약은 여전히 미확인이고, 직접 실시간 API 연결은 추가하지 않았다.

## 단기·업종 RS와 환경

- 1/3/6개월은 21/63/126개 완료 거래일 수익률이다. 같은 거래소에 저장된 유효 기업 내 백분위(동률 중간 순위)를 사용하며 5기업 미만이면 순위를 계산하지 않는다. 정지·무거래/공통일 불일치는 제외한다. 공식 전체시장 RS/IBD 수치와 같다고 주장하지 않는다.
- 업종은 시총 850억원 **초과** 유효 기업의 현재 시총 가중 수익률을 같은 거래소 분포에 대조한다. 5기업 미만 업종은 순위 대기다. 이는 투자 가능한 업종지수나 배당 포함 총수익 지수가 아니다.
- 시장 환경은 지수와 관측기업의 200일선 기준 참고 판정이다. 지수>200일선 및 관측기업 과반>200일선이면 양호, 한 조건이면 주의, 모두 아니면 방어 검토. 50/200일선 위 비율과 실제 관측 분모·상승/하락 수도 제공한다. 수급·분산일·FTD 판정을 대체하지 않는다.

## 월간 추천·변경·성과

- ‘포트폴리오 → 월간 추천 기록’에 별도 연구 기록을 추가했다. 앱을 열었을 때 이번 달 기준안이 없으면 저장 재무/가격으로 **자료 기준 초안**을 한 번 작성한다. 같은 달 재확인은 기존 월간 버전을 보존한다. 서버가 LLM을 호출하거나 월마다 개별 공시의 사업 전망을 자동 해석하는 구조는 아니다.
- 성장형 자체 규칙: 최신 분기/연속 TTM/영업현금흐름 양수, 매출 YoY≥10%, 영업이익률/ROE>0, 부채비율≤200%, 자체 RS12개월≥70·1개월≥50, 기본 가격 추세 충족. 점수는 RS12개월40%+RS1개월20%+상한100 매출 성장률25%+상한100 ROE15%다. 백테스트된 최적화/기대수익률이 아니다.
- 연구용 구성 가정: 최대5종목, 각16%, 같은 산업 최대2종목, 현금 최소20%. 자료 부족/조건 미충족 자리는 현금으로 남긴다. 개인 손실 허용도와 종목별 심층 사업 검토를 확정한 투자 지시는 아니다. 별도 모델 목표로서 실제 보유 비중을 바꾸지 않는다.
- 월중 조정은 이유 입력 후 새 버전을 작성한다. 이전 안을 보존하고 편입·제외·유지, 전후 비중, 이유와 종목별 조건을 함께 기록한다. 현재 자료가 변하지 않았다면 같은 후보가 나올 수 있다.
- 버전별 성과는 **작성일 이후 첫 완료 거래일 종가**를 진입 기준으로 잡는다. 같은 기간 KOSPI/KOSDAQ 수익률도 대조한다. 현금수익0·배당/비용/세금 제외, 고정 목표 비중의 가상 가격 성과다. 실제 계좌·버전 간 누적 실현 수익률이 아니다. 진입일/평가일 종목 가격 누락 시 성과 대기, 누락을 0수익으로 대체하지 않는다.
- 기록은 PC별 비공개 데이터 폴더의 recommendations/book.json에 저장한다. HTML 공유 후보에 넣지 않는다. 추천 기록의 PC 간 자동 동기화는 이번 범위에 추가하지 않았다. 보유 입력·주문·인증 설정과 분리한다.

## 확인 범위와 남은 한계

- 실제 저장 SK하이닉스·삼성물산·효성중공업의 검색/간단 분석 공통 값, 재무 금액 표시, 단기 RS와 가격 대조, 모바일390/320px, JS오류0 확인. 가상 응답으로 월중 조정/이전 버전/사유 기록/성과 대기 UI를 검증했다.
- 재무 전 기업 수집 완료는 아니다. 저장/TTM/ROE 계산 가능 수를 별도로 표시한다. 전체 시장 계약 시세·공식 권리변동/보통주식수·실시간 틱·사업전망을 읽은 월간 심층추천은 추가 데이터/검토가 필요하다. [DART 재무 제공 범위와 정정 유의](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS003).
