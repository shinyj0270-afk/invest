# 포트폴리오 위험 · 금융 시계열

## 연결 범위

- 월간 추천·월중 수정안은 작성 당시 완료 가격 기준 위험 분석을 저장한다. GET 조회는 같은 목표 구성의 최신 완료 가격 위험을 별도로 계산한다. 과거 목표·편입 이유·위험 분석은 덮어쓰지 않는다. 기존 추천에 작성 당시 분석이 없으면 사후 생성하지 않는다.
- 최대 5종목의 현금/종목/산업 비중, 주식 HHI, 같은 날짜 일별 수익률 상관관계, 포트폴리오 연율 변동성, 최대 낙폭, 공분산 기반 변동성 기여도를 표시한다. 이 기능은 월간 추천의 목표 구성용이며 실제 보유 입력을 변경하지 않는다.
- 추세 확인과 Advanced Visuals의 선택 기업에 누적 가격 수익률·해당 시장 가격지수·지수 초과수익, 20일 연율 변동성, 고점 대비 낙폭 차트를 연결한다. 가격 차트의 확대 범위와 별개로 분석 구간을 명시한다. 양 끝 날짜·축 단위·범례·결측 설명·마지막 5개 관측값 표를 함께 표시한다.

## 계산과 상태

1. 평가일 이하의 완료 종가만 사용한다. ISO 날짜 정렬/중복, 유한한 양수 종가, KRX, 단일 수정 기준, 종목 식별정보를 확인한다. 종목 사이의 수정 기준도 같아야 한다. 이후 가격은 작성 당시 위험에 사용하지 않는다.
2. 포트폴리오는 저장된 양대 지수의 일치 관측일을 기준으로 최대 253가격/252일별 수익률을 사용한다. 실제 시작일과 평가일을 표시하며 최소 63개 수익률이 필요하다. 종목의 첫 관측일 이후 공통 구간에서 거래일 누락·추가·최종일 미확보를 교집합/0/보간으로 숨기지 않는다. 단일 기업도 해당 시장 지수의 정확한 날짜를 대조한다.
3. 단순 일별 가격 수익률 r=P(t)/P(t-1)-1, 표본 공분산/표준편차(n-1), 연율 √252. 상관계수는 동일 구간 공분산을 양쪽 표준편차로 나눈 값이며 분산 0이면 미확인이다.
4. 포트폴리오 일별 수익률 Σwᵢrᵢ, 현금수익 0. 이는 매일 고정 목표 비중으로 재조정하는 과거 시나리오다. 기존 추천 모델 성과의 최초 비중 고정 보유 방식과 구분한다. 누적 가격 수익률은 일별 복리, 낙폭은 관측 누적 고점 대비이며 기준일 이전 전체 생애 낙폭이 아니다. 비교지수는 시장별 목표 비중의 KOSPI/KOSDAQ 가격지수와 동일 현금 비중이다.
5. Euler 연율 변동성 기여 = wᵢ(Σw)ᵢ/σ×√252×100 %p. 합계는 전체 연율 변동성이다. 음수 기여 가능, σ=0일 때 기여도 미확인. HHI는 주식 부분 정규화 비중 제곱합이며 현금 포함 총계와 구분한다. 미확인 산업을 분산 근거로 사용하지 않는다.
6. 직전 20개 일별 수익률의 표본 변동성을 연율화한다. 초기 19개 수익률은 결측으로 표시한다. 지수 초과수익은 동일 시작일 누적 가격 수익률의 차이(%p)다.

유효 원천 관측 계산은 `SOURCE_RECORDED`, 자료 부족은 `PENDING`, 현금 100%의 주식 위험 비적용은 `SAFE_DEFAULT`다. 계산 통과만으로 `USER_CONFIRMED`/`LIVE_VERIFIED`로 올리지 않는다. 배당·세금·거래비용은 제외하며 네이버 수정 기준의 전체 권리변동 보정식·공식 KRX 확정/휴장 달력은 독립 검증되지 않았다. 가격지수도 총수익지수가 아니다.

## 추천 판단의 한계

위험을 종목별 변동성의 단순 평균이나 산업 수만으로 판단하지 않는다. 자료 부족은 추천의 추가 검토 상태에 반영한다. 사용자 손실 허용도·집중도 한도 미확정으로 기존 개발용 종목16%/현금20% 기본 비중을 위험 최적화값으로 선언하거나 자동 변경하지 않는다. 위험 최적화·개인화 손실 제한·주문 연결은 이번 구현 범위가 아니다.
