# 통합 투자 대시보드 재검토와 다음 개선안

점검일: 2026-10-02. 이 PC의 로컬 작업본과 저장 자료 기준이다. **확인한 오류는 수정했고, 데이터 제약을 표시한 상태로 사용할 수 있다.** 메뉴 경로 전체를 점검하되 모든 기업·모든 공시 계정을 수작업 대조한 것은 아니므로 수치 검증 범위는 부분 검증이다.

## 수정한 오류

1. **이전 재무 해석값이 그대로 남는 문제.** 복구 도구가 예전 값을 새 버전으로 표시하는 경로를 제거했다. 저장 공시 7,391건을 HTML 원문에서 다시 해석했다. 지배·비지배 손익 또는 자본 합계가 맞지 않던 28기업·45건을 확인했고, 검증되지 않는 귀속 계정은 계산에서 제외했다. 매출·영업이익·총순이익 같은 검증된 항목은 유지한다.
2. **분기 EPS 계산 오류.** 누적 EPS끼리 빼면 중간에 주식수가 달라진 경우 단독분기 EPS와 달라진다. 1분기·연간 원문 EPS는 유지하고, 2~4분기 단독 EPS는 원문이나 주식수 근거를 확보할 때까지 미확보로 표시한다. 별도 가치평가 화면의 주식수 고정 근사는 계속 근사로 표시한다.
3. **거래 없는 종목의 추세 통과 표시.** 거래량이 0인 실제 종목에서 기본 진단은 보류인데 스탁이지 공개식 참고 판정만 통과한 경우를 확인했다. 두 판정에 같은 거래 상태 조건을 적용했다.
4. **월초 추천의 재무 기간 오류.** 아직 공시되지 않은 분기를 요구해 정상 후보가 전부 제외될 수 있었다. 공시가 모이는 시기를 반영한 보수적인 최신성 하한으로 수정했다. 10월은 기존처럼 반기 자료가 필요하다. 과거 추천 기록은 당시 판단으로 보존한다.
5. **상세 차트의 52주 범위 누락.** 오늘까지 공개된 재무를 읽는 날짜가 가격 완결 날짜에도 쓰여, 장중에 전일 종가까지 모두 있어도 범위를 미확보로 표시했다. 가격 차트는 양대 지수에서 검증한 마지막 완료 거래일을 사용한다. 실제 가격일 누락이 있으면 여전히 완전한 범위라고 표시하지 않는다.
6. **상세 상단 PER의 근사 표시 누락.** 요약 카드에는 근사라고 쓰면서 상단에는 PER(TTM)만 표시하던 불일치를 고쳤다.

## 검증 범위와 남은 제약

- 메뉴 20개를 실제 로컬 데이터로 열어 보고 1,440/390/320px에서 페이지 너비 넘침과 자바스크립트 오류를 점검했다. 홈·검색·간단 분석·가격 추세·상세·추천의 화면을 표본으로 시각 검토했다. 반복 차트의 모든 종목 조합을 눈으로 확인하지는 않았다.
- 독립 검산은 공시 귀속 합계 전체, 단기 RS의 실제 종목 표본, 추천 월초 기간 경계, EPS 주식수 변동 사례, 거래 없는 날의 추세 판정에 집중했다. 검색과 간단 분석의 같은 값은 화면 일관성 검사이며 별개의 원천 검증으로 세지 않는다.
- 가상 자료를 이용한 보유 입력·시나리오·CSV/관심목록·차트·자동/수동 갱신·실패/복원·월간/월중 기록 테스트를 별도로 수행했다. 개인 보유내역에 시험 데이터를 쓰지 않았다.
- 재무 확보 1,322/1,371개, 최신 반기 1,238개, 연속 4분기 1,184개, 전체 미확보 49개다. 저장기업 수가 모든 지표의 완전 확보를 뜻하지 않는다. 원천 시세시각·KRX/NXT 범위·전 종목 권리변동 보정·과거 정정 전 공시의 재현은 여전히 확인이 필요하다.
- 스탁이지 비교는 현재 공개 홈페이지·공개 종목 요약·매뉴얼·RS 정의를 사용했다. 실제 브라우저에서는 로그인 요구가 나와 회원 전용 화면의 세부 동작은 검증하지 못했다. 원천 시세 공급 계약이나 스탁이지 내부 계산을 확인했다고 주장하지 않는다.

## 허용 오차에 관한 사용자 결정

근거가 일부 부족해도 허용 오차 안이라는 충분한 근거가 있으면 참고값으로 표시해 사용한다. 기존 금액 차이 1억원 미만 기준을 유지한다. ‘90%’는 사용자가 원하는 신뢰 수준이며, 현재 시스템에 이를 측정한 통계적 보정 자료는 없다. 계정·기간·단위가 같은 독립 계산과 확인 가능한 오차를 우선 사용하고, 근거 없이 확률 숫자를 붙이지 않는다. 서로 다른 계정이나 연결/별도 혼합은 작은 잔차만으로 같은 수치라고 판단하지 않는다.

원문에 지배·비지배 계정이 각각 명시되고 같은 기간·단위이며 합계 잔차가 1억원 미만인 11개 보고서는 참고값으로 복원했다. 파생 ROE는 6개가 복원되어 최종 1,016개다. 각 잔차와 해당 기간을 화면 설명에 보존한다. 원문 한 건의 금액 잔차가 작다는 사실을 TTM·비율 오차의 동일한 상한이나 90% 확률로 일반화하지 않는다.
