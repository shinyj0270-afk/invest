### 보유 비중 보류 원인 · 2026-10-15

- 비중 의견과 표 아래 안내는 같은 전체 자산 계산의 미완료 원인을 사용한다. 현금 미입력, `기업명(코드) 가격 확인 필요`를 구분하고 여러 원인은 함께 표시한다. 이름 미확보는 종목코드를 사용한다. 다른 종목 가격이 없어서 현재 종목의 비중도 보류되는 경우에도 실제 누락 종목을 명시한다.
