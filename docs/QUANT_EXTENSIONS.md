# 이동 위험·업종 분해·가설 후속 관찰

GS Quant 검토에서 채택한 기능을 기존 로컬 계산으로 확장한다. GS 코드 복제·패키지 설치·Marquee API/데이터 연결 없이 기존 가격·달력·Research Library를 재사용한다. 기존 구성 한도·수집·주문 금지·개인정보 공유 제외 계약을 유지한다.

## 시장 민감도와 동행성

추세 분석과 추천 포트폴리오 위험 아래에 63/126거래일 이동 베타·시장 상관을 표시한다. 추천 구성에는 같은 기간 종목 간 이동 상관도 제공한다. 두 시계열의 같은 날짜 단순 수익률에 표본 공분산/분산을 사용한다. 완전 관측창 이전·상수 비교지수의 베타는 미확인, 한쪽 분산0의 상관은 미확인이다. 상수 종목/변동 지수의 베타0과 상관 미확인을 구분한다. 변화는 동일 길이 직전 비중첩 창 대비다.

기존 완료 종가·KRX·수정기준·중복/정렬·정확한 공통 관측일 검사를 먼저 통과해야 한다. 누락을 교집합·0·보간으로 숨기지 않는다. 베타는 배, 상관은 계수 -1~1이며 미래 손실 한도나 매매 신호가 아니다. 기존 수익률·변동성·MDD 산식을 변경하지 않는다.

## 산업 강세의 폭

산업 상세에서 기존 200일선 위 비중에 50일선 위 비중과 기간별 가중방식 비교를 연결한다. 각 21/63/126거래일 관측기간 안에서 양수 시총·수익률이 모두 있는 같은 기업만 현재시총 가중·동일가중 평균·중앙값으로 비교하고 기업수·제외수를 표시한다. 시총 상위3 기업의 기여는 각 현재시총 비중×기간 가격수익률의 합(%p)이다. 절대기여 비중은 상위3 절대기여/전체 절대기여이며 분모0은 미확인이다. 상승·하락의 상쇄 때문에 기여 비중이 왜곡되지 않도록 부호 있는 %p와 절대비중을 분리한다.

현재 구성·현재 시총의 관측 분해이며 당시 업종지수나 투자 가능한 백테스트 수익률이 아니다. 5기업 미만 순위 대기·같은 거래소 비교·산업 미확인 및 기존 업종 분류 계약을 유지한다. 과거 당시 기업/시총을 확보하지 못한 상태에서 역사적 업종 성과로 승격하지 않는다.

## 가설 후속 관찰

Research Library의 출처·권한·삭제 검사를 통과한 현재 가설 revision에만 후속 관찰을 붙인다. 원래 DB와 가설 revision은 변경하지 않는다. 명시적 CLI가 `.local/research-followup/{profile}/`에 가설 digest·후보 기업/시장/산업·선정규칙·고정시각·평가규칙을 독립 JSON으로 한 번 저장한다. 같은 입력은 재사용하며 기존 계획의 후보 변경은 거부한다. 계획은 연구 코호트이며 실제 추천 구성이나 주문이 아니다.

후보 고정일 **다음** 첫 완료 관측일 종가를 기준으로 63/126/252거래일 후 가격을 평가한다. 달력상의 정확한 3/6/12개월과 다른 약정이며 화면에 거래일 수를 표시한다. 기업별 동일 초기비중 고정보유, 시장별 초기비중 KOSPI/KOSDAQ 혼합 가격지수, 누적 수익 차이(%p), 관측 경로 MDD를 제공한다. 배당·비용·세금은 제외한다. 미래기간 미도래는 대기, 한 기업 가격 누락·상폐·수정기준 불일치는 해당 기간 전체 자료 대기이며 후보를 제거하거나 0으로 채우지 않는다. 가설 기록일 이전으로 소급 고정할 수 없다.

이 결과는 가격 관찰이며 산업 확산·ROIC/CAP의 독립 설명력이나 가설 인과 검증을 자동 수행하지 않는다. 조건/반증과 당시 설명변수의 별도 관측·교란요인 통제가 필요하다. 충분한 기간이 지나기 전 성공/실패·성과 수치를 생성하지 않는다. GET은 파일·DB를 생성하거나 계획을 갱신하지 않는다. 스케줄·무인 실행·자동 가설 승격도 없다.

```powershell
.\.venv\Scripts\python.exe tools/research_followup.py freeze --id THESIS-20261026-01 --input .local/research-followup-inputs/THESIS-20261026-01.json
.\.venv\Scripts\python.exe tools/research_followup.py status --id THESIS-20261026-01
```

입력 JSON은 `candidates`(code/market/name/industry 객체 배열 1~500개)와 `selection_rule`을 요구한다. 후보는 사용자가 지정하거나 이미 확정한 산업 매핑을 적용한 명시 목록이며 유사 이름으로 추정하지 않는다. 코호트에는 실제 개인 보유를 자동 사용하지 않는다. 개발 워크트리 CLI의 `--project-root`로 원본 PC의 기존 로컬 설정·DB를 참조할 수 있다. 설정/DB를 복사하지 않는다. 다른 PC에 계획/DB를 자동 전송하지 않는다.

## 검증

`tests.test_rolling_relationship`: 독립 covariance/variance/correlation, 동일/역상관, 상수, 준비 구간, 누락 거래일과 기존 가격 계약.
`tests.test_sector_weighting`: 알려진 가중/평균/중앙값·부호 있는 기여·절대기여·분모0·후보 제외.
`tests.test_research_followup`: 소급 금지·계획 중복/충돌·hash·revision·고정 초기비중·기간별 평가·미도래·누락·미래 누출·입력 불변성.
`tests/test_quant_extensions_ui.py`: 이동 차트/후속 관찰 대기·XSS 방지·1440/390/320px. 기존 산업/추세/추천/Library UI 및 격리 portable/UI 검증도 적용한다. 합성 성공을 실데이터 후속 성과로 해석하지 않는다.
