# 추세추종 화면

## 사용자 요청과 위치

2026-10-07 사용자 제공 「추세추종 전략: 스탁이지와 마크 미너비니를 중심으로」(문서 표기 2026-10-03)를 참고해 기업 찾기의 하위 탭을 **추세추종 → 조건검색 → 산업별 후보** 순서로 배치했다. 글의 성과 주장이나 실행 지시를 프로그램의 확정 사실·매매 승인으로 취급하지 않는다.

사용자 추가 결정: 기본 시가총액 하한 **1,000억원 이상(경계 포함)**. 글의 2,000억원을 그대로 적용하지 않는다. 기본 RS70은 화면에서 조정 가능한 참고값이며, 개인 위험 한도나 자동 추천 정책 변경을 뜻하지 않는다.

## 화면 구성

- 시장: KOSPI/KOSDAQ 완료 가격과 50/150/200일 이동평균 차트. 지수 가격/50일/200일 배열과 200일선의 21거래일 전 대비 변화로 자체 참고 국면을 표시한다. 스탁이지의 비공개 신호등·오닐 FTD와 동일하다고 주장하지 않는다.
- 산업: 기존 시총 가중 1개월 RS 기준 상위6개 산업과 같은 기준일 거래량 동반 돌파 수. 클릭하면 시장/산업 필터로 연결한다. 시간순 돌파 이력·ETF 자금흐름·전체 시장 산업지수와 구분한다.
- 후보: 시총1000억원·RS70 기본, 이름/코드·시장·시총·RS·차트 조건·정렬 조정. 6개 차트씩 표시, 종가/50/150/200일선/20일 최고종가 돌파선/거래량 및 8조건 점검. 후보가 없으면 빈 상태와 자료 대기를 명시한다.
- 확대: 선택 기업의 기존 인터랙티브 차트(범위·이평선·OHLC 확보 시 캔들)와 8조건·거래량·수축 수치를 연결한다. 재무/촉매 검토와 기존 가격 추세 상세로 이동할 수 있다.
- 근거: 글의 5단계 및 -8%/+24% 관리 예시, 적용/미적용 조건과 출처를 접을 수 있는 설명에 제공한다. 주문·보유·포트폴리오 설정은 변경하지 않는다.

## 계산·자료 계약

`investment/trend_following.py`는 기존 RS·가격 분석을 재사용하고 완료 가격의 종목 식별·평가일·유한 양수·KRX·단일 수정 기준·해당 지수와 날짜 일치를 검증한다. 결측/잠정/식별 불일치/거래 없음은 후보 통과로 처리하지 않는다. 미래 가격은 기준일 이하 계산에 사용하지 않는다.

8조건은 기존 `trend_diagnostics.diagnose`의 종가 기반 변형이다. 최저종가 대비 +30%, 최고종가 대비 -25% 이내, 자체 RS70을 사용하며 공식 IBD RS/장중 고저가/SEPA 전체와 구분한다. 자체 RS의 모집단은 같은 거래소의 저장 유효기업이고 필터로 순위를 재계산하지 않는다. 기존 원본의 시총850억원 초과 탐색 범위도 유지한다.

20일 최고종가는 기존 관찰용 돌파선이다. 7주 베이스·최종 VCP 수축 고점·컵앤핸들 자동 판정이 아니다. 수축 참고는 세 10일 종가 범위 축소와 10/60일 변동성비·5/50일 거래량비 0.7 미만이다. 거래량 동반 돌파는 종가 돌파와 직전50일 평균 거래량의 1.5배를 사용한다. 가격만 통과하거나 거래량 미확보면 별도 문구를 유지한다.

초기 차트는 기본 조건의 RS상위21개까지 포함하며 각253관측으로 제한한다. 그 밖의 현재 페이지6개는 기존 `/company-view` 읽기 경로로 동시 최대2개씩 조회한다. 필터 변경/페이지 이탈 시 대기 작업을 제한하고 화면 상태를 보존한다. 미리보기는 최근126개 관측, 각각 원/지수pt/거래량주 단위와 날짜를 명시하며 종목마다 별도 가격 축이다. 실제 저장 이력이 없을 때 가상 가격으로 대체하지 않는다.

## 참고 자료와 차이

- 사용자 첨부 문서의 시장 → 산업 → 종목 → 진입 → 관리 순서와 차트 중심 구성을 적용했다.
- [스탁이지 공개 RS/MMT 정의](https://stockeasy.intellio.kr/guide/rs), 2026-10-07 조회: 자체 RS와 공개 정의의 모집단 차이, 고가/종가 기준 차이를 명시한다. 고가 ≤ 종가×1.25는 고가 대비 -20% 이내로서 -25% 조건과 동일하지 않다.
- [미너비니 공식 사이트의 워크숍 소개 자료](https://cdn.minervini.com/static/dist/mtp-review.1f8e8633.pdf), 2026-10-07 조회: 추세·상대강도·셋업과 위험 관리의 참고 자료이며 유료 워크숍 전체 규칙을 복제하지 않는다.
- EPS/기관 매수/촉매/ETF 흐름/FTD/분산일/7주 베이스/베이스 카운트는 아직 자동 검증하지 않는다. 가격 조건 충족을 이 요소들의 충족이나 주문 신호로 바꾸지 않는다.
