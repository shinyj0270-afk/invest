# 국내 기업 분석 범위 확대

## 목표

현재 실제 3종목에서 코스피·코스닥의 일반 비금융 기업으로 기업 발굴 대상을 확대한다. 기업명만 추가하지 않고 수익성·재무·가치평가 조건검색과 기업별 근거 확인에 사용할 실제 수치를 연결한다. 가격 추세 순위와 지수 초과수익은 필요한 가격 근거가 확보된 범위에서 계산한다.

## 데이터 원칙

- 인포맥스 기존 3종목 원본·DB·보유 입력을 보존한다. 새 공개 시장 자료는 PC 로컬 별도 캐시에 저장한다.
- 종목 목록의 전체 수, 분류 제외 수, 수집 성공/실패 수와 지표별 확보 수를 기록한다. 수집 실패를 0이나 가상값으로 바꾸지 않는다.
- 보통주/우선주·ETF/ETN·SPAC·REIT·금융업을 구분한다. 추측으로 적격 판정을 통과시키지 않고 미확인 분류는 별도 표시한다.
- 네이버 제공 비율과 직접 계산한 비율을 구분한다. PER/PBR은 양의 분모 근거가 있는 경우만 가격 매력 조건에 사용한다. 시가총액은 원/억원 단위를 검증한다.
- 재무 기간·연결/별도·산식이 확인되지 않은 수치는 그 한계를 표시한다. 기존 검증 스냅샷의 동일 기준 수치로 가장하지 않는다. 기업별·지표별 출처와 기준일을 유지한다.
- 장중 시세는 확정 종가로 사용하지 않는다. 수정주가·거래일·종목 정체성이 확인되지 않으면 RS는 보류한다. 주가 관측 이력 자체는 출처와 상태를 붙여 별도로 사용할 수 있다.
- 조회는 명시적 1회 수집이며 예약·실시간 반복 조회를 추가하지 않는다. 페이지·기간·크기 제한, 실패 기록, 캐시 재사용과 낮은 동시성을 사용한다.

## 통합 방식

기존 분석/보유 스냅샷 계약과 별개로 출처가 명시된 기업 발굴용 자료를 구성한다. 화면은 데이터 범위·유효 수치·날짜를 표시하고, 필터와 CSV에 같은 전체 모집단을 적용한다. 비교군은 지표의 기간·회계·산식이 일치하는 경우에만 같은 기준으로 비교한다. 공개 자료를 보유 판단의 확정 근거로 자동 승격하지 않는다.

## 검증

실제 전체 수와 페이지 중복/누락 확인, 유형/업종 제외, 결측·음수 분모·단위·미래일·기간 불일치, 원본 보존, 캐시 재시작/부분실패, 전체 필터/CSV/브라우저 검색을 확인한다. 완료 시 실제 확보 수와 남은 데이터를 기록한다.

## 2026-09-30 실제 연결 결과

- 네이버 공개 시장 목록 2,768개: 코스피 944개, 코스닥 1,824개. 모든 페이지의 끝을 확인했고 목록·업종 수집 오류는 0건이다.
- 금융·우선주·ETF/ETN·SPAC·리츠 등 명시적 제외 313개, 비금융 일반주 후보 2,455개. 후보 표시는 법적 주식 종류를 모두 확인한 확정 분류가 아니다.
- 지표 확보: ROE 2,449개, 영업이익률 2,445개, 매출 증가율 2,445개, 부채비율 2,437개, 양수 PER 1,528개, PBR 2,433개, 양수 PER·PBR 동시 1,521개.
- 2025-01-17~2026-09-29 완료 일봉: 2,454개 수집, 1개(덕산넵코어스 266690) 원천 응답에 해당 범위 완료 일봉이 없어 보류. 253관측일을 충족한 동일 시장 가격 추세 순위는 2,290개(코스피 726개, 코스닥 1,564개)다.
- 종목 가격은 네이버 차트의 조정 가격을 사용한다. 삼성전자 액면분할 구간 보정은 표본 확인했지만 모든 권리변동의 보정식은 미공개다. KOSPI/KOSDAQ 일반 가격지수는 총수익지수가 아니다.
- 네이버 목록 재무 수치에는 정확한 보고기간과 연결/별도 구분이 없다. 조건검색에서는 `참고`로 표시하고, 기존 인포맥스 3종목의 검토 수치가 있으면 그 값을 우선한다. 동일 기간·기준이 필요한 업종 중앙값은 계산하지 않는다.
- 가격 추세 조건에서 거래대금 기준은 보류한다. 공개 일봉의 거래대금이 없어 가격 배열·이동평균·수익률·지수 초과수익만 별도로 표시한다.
