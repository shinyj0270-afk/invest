# 산업 연구 화면 · 2026-10-19

상단 메뉴 **산업 연구**(홈 섹터 맵의 `산업 연구 →`)에서 산업 개요 → 산업 상세 → 구성기업 · Research Library · 원문 순서로 살펴본다. 새 사이트나 별도 대시보드가 아니라 기존 통합 대시보드의 한 화면이다. 코드: `src/industry_engine.js`(집계), `src/industry_ui.js`(화면), `src/industry.css`.

## 사용하는 자료와 정의 (관측)

| 항목 | 출처 · 정의 |
|---|---|
| 산업 · 구성 | 네이버 공개 업종 분류, 시가총액 1,500억원 초과 탐색 대상(`discovery_allowed`). 시장(KOSPI/KOSDAQ)별로 따로 묶는다 |
| 1/3/6개월 RS · 가중 수익률 | 기존 `market_insights.sectors` 재사용(21/63/126 완료 거래일, 현재 시총 가중, 같은 거래소 분포 백분위, 5개 미만이면 없음). 자체 RS이며 IBD 공식 RS가 아니다 |
| 200일선 위 비중 | 가격이 확인된 구성기업 중 완료 종가 > 200일 단순이동평균 비율 |
| 3개월 양수 비중 · 1개월 중앙값 · 최대 기업 제외 가중 1개월 | 기존 기업별 `short_rs` 수익률로 계산. 가격 미확보 기업은 분모에서 제외 |
| 최대 기업 비중 · 상위 3개 비중 | 양수 시가총액 합계 대비 |
| 매출성장률 · 영업이익률 · ROE · 부채비율 중앙값 | 기존 `DiscoveryEngine.sectors` 재사용. 기간·회계기준이 모두 같을 때만 표시 |

정렬은 관측값 정렬이다. 정렬 기준값이 없거나(RS) 유효 기업 5개 미만(200일선·시가총액)인 산업은 순위 없이 이름순 "자료 부족" 목록에 둔다. 주도산업 판정·투자 판단을 하지 않는다.

미확보로 표시하고 계산하지 않는 지표: 실적 확산(영업이익 증가 기업 비중), 마진 변화, ROIC·WACC, 수주잔고·산업 통계, 투자 가능한 업종지수 총수익률.

## 연구 연결 (해석 · 검증 전)

- 실행 앱에서 기존 읽기 전용 `/research-library` projection을 GET으로만 읽는다. 삭제/제외·권한 철회·Telegram 차단은 기존 projection 규칙을 그대로 따른다. DB 생성·입력·revision 변경 없음.
- 연결 규칙: 연구의 종목 연결이 구성기업과 같으면 "구성기업 직접 연결", 연구 산업 태그가 산업명에 포함되거나 같으면 "산업명 대응 후보 · 사람 확인 전". 대응표를 새로 만들지 않는다. 예: `반도체` → `반도체와반도체장비` 대응, `전력기기`는 자동 대응하지 않고 "다른 연구 산업" 버튼으로 Library에서 연다.
- 가설 상태는 `연구 중 · 검증 전`/`반증됨`/`연구 종료`로만 표시한다. 연구 기록일·내용 기준일·원문 발행일·확인일을 따로 보이고, 기록·출처·revision 수를 독립 근거 수로 합산하지 않는다.
- 회사 결과 조회(정적 공유) 화면과 토큰 없는 정적 HTML은 연구를 요청·표시하지 않는다.
