# 산업 연구 화면 · 2026-10-19

상단 메뉴 **산업 연구**(홈 섹터 맵의 `산업 연구 →`)에서 산업 개요 → 산업 상세 → 구성기업 · Research Library · 원문 순서로 살펴본다. 새 사이트나 별도 대시보드가 아니라 기존 통합 대시보드의 한 화면이다. 코드: `src/industry_engine.js`(집계), `src/industry_ui.js`(화면), `src/industry.css`.

## 사용하는 자료와 정의 (관측)

| 항목 | 출처 · 정의 |
|---|---|
| 산업 · 구성 | 네이버 공개 업종 분류, 시가총액 1,500억원 초과 탐색 대상(`discovery_allowed`). 시장(KOSPI/KOSDAQ)별로 따로 묶는다 |
| 1/3/6개월 RS · 가중 수익률 | 기존 `market_insights.sectors` 재사용(21/63/126 완료 거래일, 현재 시총 가중, 같은 거래소 분포 백분위, 5개 미만이면 없음). 자체 RS이며 IBD 공식 RS가 아니다 |
| 200일선 위 비중 | 가격이 확인된 구성기업 중 완료 종가 > 200일 단순이동평균 비율 |
| 3개월 양수 비중 · 1개월 중앙값 · 최대 기업 제외 가중 1개월 | 기존 기업별 `short_rs` 수익률로 계산. 가격 미확보 기업은 분모에서 제외 |
| 최대 기업 비중 · 상위 3개 비중 | 양수 시가총액 합계 대비 |
| 매출 증가 기업 비중 | 기존 저장 매출성장률이 0보다 큰 기업 비율. 산업 안에서 가장 많은 기업이 공유하는 기간·회계기준 묶음만 분모로 쓰고(동수면 최근 기간), 기간·기준 미확인이나 다른 묶음은 제외 수로 표시 |
| 영업이익 증가 기업 비중 | 검증된 저장 단독분기의 영업이익 금액이 전년 같은 분기보다 큰 기업 비율. 같은 현재/전년 비교기간·연결/별도·통화 묶음 중 최다 기업 묶음만 분모(동수면 최근 기간). 흑자 증가·흑자 전환·적자 축소와 적자→손익분기·0→흑자를 구분. 감소·동일은 분모에 포함, 비교자료 미확보와 다른 묶음은 별도 표시 |
| 매출성장률 · 영업이익률 · ROE · 부채비율 중앙값 | 기존 `DiscoveryEngine.sectors` 재사용. 기간·회계기준이 모두 같을 때만 표시 |

정렬은 관측값 정렬이다. 정렬 기준값이 없거나(RS) 유효 기업 5개 미만(200일선·시가총액)인 산업은 순위 없이 이름순 "자료 부족" 목록에 둔다. 주도산업 판정·투자 판단을 하지 않는다.

전체 시장을 선택해도 KOSPI·KOSDAQ의 목록과 순번은 따로 표시하며 시장마다 1위부터 시작한다. 자료 부족 목록도 시장별로 구분한다. 최대 기업 제외 수익률은 전체 양수 시총 구성기업에서 최대 기업을 먼저 정하고 그 코드만 수익률 유효 집합에서 제외한다. 최대 기업의 가격이 미확보여도 다른 기업을 대신 제외하지 않는다.

영업이익 비교는 기존 재무 표의 공식 원문 우선·단독분기 누적 차감·회계달력·공시 기준일 검증과 전년 동기 매칭을 재사용한다. 누적/연간을 분기 대신 쓰거나 전년 금액을 분모로 증가율을 만들지 않는다. 영업이익률·현재 흑자 여부·주가 상승으로 대체하지 않는다. 비교기간의 원문 출처·공개일 미확인·계정 차이 주석을 보존한다. 종목의 현재/전년 금액은 같은 단위로만 비교하며 통화 환산이나 기업 간 금액 합산은 하지 않는다.

미확보로 표시하고 계산하지 않는 지표: 마진 변화, ROIC·WACC, 수주잔고·산업 통계, 투자 가능한 업종지수 총수익률.

## 연구 연결 (해석 · 검증 전)

- 실행 앱에서 기존 읽기 전용 `/research-library` projection을 GET으로만 읽는다. 삭제/제외·권한 철회·Telegram 차단은 기존 projection 규칙을 그대로 따른다. DB 생성·입력·revision 변경 없음.
- 연결 규칙: 연구의 종목 연결이 구성기업과 같으면 "구성기업 직접 연결", 연구 산업 태그는 `config/industry_sector_map.json`의 사용자 확정 대응표(2026-10-19)로만 "사용자 확정 산업 대응표 연결". 문자열 유사성만으로 연결하지 않는다. 확정값: 반도체→반도체와반도체장비, 전력기기→전기장비(전기제품은 2차전지 중심이라 제외), 조선→조선, 화학→화학. 복합 태그(KRX 반도체 장비·전력기기·산업자동화, KRX 금리 민감 업종)는 대응하지 않고 "다른 연구 산업" 버튼으로 Library에서 연다. 파일이 없거나 형식이 틀리면 종목 직접 연결만 표시한다.
- 가설 상태는 `연구 중 · 검증 전`/`반증됨`/`연구 종료`로만 표시한다. 연구 기록일·내용 기준일·원문 발행일·확인일을 따로 보이고, 기록·출처·revision 수를 독립 근거 수로 합산하지 않는다.
- 회사 결과 조회(정적 공유) 화면과 토큰 없는 정적 HTML은 연구를 요청·표시하지 않는다.
- 대응표는 정수 version=1, decided_by="user", 실제 달력에 존재하는 YYYY-MM-DD 형식의 decided_on을 요구한다. 승인 정보나 대응 목록의 형식이 잘못되면 빈 대응표로 처리하고 종목 직접 연결만 유지한다.

## 산업별 국면 확산 (2026-10-19 작업 워크트리 구현)

사용자 결정(2026-10-19): 투입 자료 DS투자증권 「순환주기론」(Library SRC-20261019-DS01, THESIS-20261019-05)의 아이디어를 자체 고정 규칙으로 구현한다. 보고서의 학습 엔진 재현이 아니다. 기준값은 제안값으로 시작해 설정 파일(예: `config/industry_phase.json`)에 고정하고 화면에 정의를 표시한다. 가설 C 검증 결과를 본 뒤 다시 정한다.

- 종목 국면(저장 완료 종가·이동평균만 사용): 생 = 사 국면 이후 60거래일 최고종가 돌파 / 왕 = 50일선>200일선이고 52주 최고종가 대비 하락 10% 이내 / 쇠 = 고점 대비 10~20% 하락 또는 50일선 이탈 / 사 = 고점 대비 20% 초과 하락 또는 50일선<200일선. 가격 이력 부족·미확보는 미확인.
- 산업 지표: 생+왕·쇠+사 비중(기업 수·시총), 최근 20거래일 쇠 진입 기업 수(꺾임 경보). 유효 5개 미만은 비순위 규칙 유지, 시장별 분리.
- 화면: 산업 개요 "국면 확산" 열, 산업 상세 구성기업 국면 열과 정의. 관측값 배지, 주도산업 판정 아님.
- 계산 위치: 전체 가격 이력을 가진 서버측 export(market_insights와 같은 단계). 기존 RS·200일선 계산 재사용, 새 수집 없음.
- 검증: 단위(경계값·결측·이력 부족)·화면(1440/390/320px)·격리 UI 검사, 저장 가격으로 정점→꺾임 기간 분포를 계산해 가설 C의 비대칭 재현 여부를 문서화.
- 이어서 구현: 수익률×거래대금 변화 3×3 분류([주도주 전략](LEADER_STRATEGY.md), 원문 URL 미확인 표시).

`investment/industry_phase.py`가 가격 이력을 읽어 export 단계에서 계산한다. 최신 50/200일선은 기존 기술 관측값을 재사용하고 과거 국면에는 같은 단순이동평균을 적용한다. 원자료를 수집·수정하지 않으며, 전체 국면 이력을 HTML에 중복 포함하지 않는다. `config/industry_phase.json`에 기준을 고정했다.

겹치는 조건의 구현 기본 우선순위는 **생→사→쇠→왕**, 그 외 미확인이다. 이는 추가 질문에 답변이 오기 전 공개한 기본값이며 사용자 확정 결정과 구분한다. 사를 실제 관측한 뒤 현재일을 제외한 직전 60거래일 최고종가를 처음 초과하면 생이며, 생 발생 시 대기 상태를 해제한다. 사가 다시 관측되면 다시 대기한다. 정확히 10% 하락은 쇠, 정확히 20%도 쇠이며 20% 초과는 사이다(이동평균 조건과 우선순위는 별도). 왕은 50일선=200일선이면 성립하지 않는다.

52주는 달력 364일의 종가 최고값이며 전체 52주와 200관측일이 확보되어야 한다. 기존 공통 거래일 검증을 통과한 완료 가격만 사용한다. 기준일 불일치·거래정지·마지막 거래 없음·이력 부족은 미확인이다. 국면 미확인은 기업 비중의 분모에서 제외하고, 시총 비중은 그중 양수 시총 확보 기업만 분모에 포함한다. 최근 쇠 진입은 직전 국면이 확인된 다른 국면일 때만 세며 최근 20관측일 중 중복 기업을 1개로 센다. 현재 쇠 유지 기업 수와 다르다. 국면 확산은 새로운 순위나 주도산업 판정을 만들지 않는다.

가설 C는 좌측 이력이 잘린 구간·미완료 구간·상승 기간 0을 제외하고, 관측 가능한 쇠/사→생/왕 시작부터 해당 성장 구간 최고종가까지와 그 고점→첫 쇠/사까지의 거래일을 비교한다. 종목 반복 사건을 독립 근거로 세지 않으며 DS 학습 엔진이나 통계적 가설 검정의 재현이 아니다. [저장 자료 관측 점검](STRATEGY_OBSERVATION_CHECK.md)에 시장별 분포를 기록한다.
