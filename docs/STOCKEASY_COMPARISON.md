# 스탁이지 데이터 연결과 현재 로컬 대시보드 비교

점검일: 2026-10-02. 대상은 이 PC의 미커밋 개발 작업본과 저장 기업 캐시다. 원격 origin/main의 배포 상태 또는 다른 PC의 실행 상태를 뜻하지 않는다. 코드 수정·추가 수집·주문·외부 문의는 실행하지 않았다.

## 확인한 스탁이지 연결 범위

- [고객센터](https://stockeasy.intellio.kr/support)는 제공처 사정에 따른 지연·오류 가능성을 안내한다. 거래소 체결 실시간과 정확한 지연시간을 보장한다고 확인하지 못했다.
- [소개·매뉴얼](https://stockeasy.intellio.kr/about)은 테마보드 1분 자동 갱신과 전략실 장 종료 후 갱신을 별도로 설명한다. 전략실의 장후 설명을 사이트 전체 갱신 주기로 일반화하지 않는다. 화면 재조회 주기는 원천 체결 지연시간이 아니다.
- [RS 정의](https://stockeasy.intellio.kr/guide/rs)는 전일 종가까지 누적 추세로 전체 종목 백분위를 계산하고 기간별·섹터·지수 RS도 제공한다고 설명한다.
- 홈페이지가 직접 연결하는 공개 JavaScript 40개를 읽었다. 시장보드·RS·차트는 `/api/v1/market-board/landing-data`, `/api/v1/market-board/macro-bar`, `/api/v1/rs/dashboard-data`, `/api/v1/stock/chart/` 등 자체 경로를 요청한다. 브라우저가 화면용 API를 읽는 것은 확인되지만, 서버가 어떤 원천 공급자를 쓰는지는 이것만으로 알 수 없다. 내부 수집·정규화·캐시 구조는 추정이다.
- 공개 종목 요약은 최근 실적을 회사 공시 기준·연결로 표시하고 공개 스크립트에는 DART 링크가 있다. 이것은 공시 원문 연결의 증거이며 DART가 모든 재무·가격의 수집 공급자라는 증거가 아니다.
- FnGuide라는 ETF 추종지수명이나 AI 리포트의 출처 표시는 실시간 시세 공급 계약의 증거가 아니다. 인포맥스·FnGuide·증권사 API 중 어느 것을 실시간 공급자로 사용하는지 확인하지 못했다.
- 공개 스크립트에 실제 표시된 시장보드 조회 두 경로를 인증 없이 확인했으나 403 응답이었다. 우회·로그인·비공개 조회는 하지 않았다. 자료 공급 계약·주기·KRX/NXT 구분은 운영자의 공개 설명이 더 필요하다.

## 우리 쪽 실제 자료 흐름

- 가격 이력: 네이버 공개 차트의 KOSPI/KOSDAQ 및 종목 일봉. 일부 액면분할 표본 보정 확인은 있으나 전 종목 권리변동·거래량 조정 정의는 미확인이다.
- 새로고침 가격: 네이버 공개 전체 목록을 읽어 기존 기업의 가격·시총을 별도 저장한다. 조회시각은 있으나 체결시각·지연시간은 없다. 확정 종가/추세에 합산하지 않는다.
- 재무: 인포맥스 저장 파일 우선, 미확보 기업은 공개 DART 연결 보고서 HTML 조회·검증·저장. 인포맥스 신규 기업 자동 API 연결은 없다. 이번 점검에서 OpenDART 인증 API를 새로 연결하거나 키 상태를 확인하지 않았다.
- 재무 갱신: 신규 분기 즉시 반영, 동일 기간 정정은 마지막 반영값 대비 7% 이상 또는 부호변경·0기준 변경을 반영한다. 작은 수정은 보류한다. 일간 모니터는 현재 사업·반기·분기보고서 제목을 대상으로 하며 모든 종류의 공시·잠정실적 이벤트를 감시하는 것은 아니다.
- 자동 갱신: 앱을 열고 열린 화면에서 상태를 요청할 때 실행되는 구조다. 닫힌 PC에서도 독립 실행하는 예약은 없다. 현재 일봉 종료일은 조회일의 전날로 설정하여 당일 장후 종가는 다음 날 이후에 수집한다.

## 대조와 개선 순서

1. **재무 확보·검색 지표 통일.** 상세표는 저장 DART 자료를 읽지만 기업 검색의 재무 지표는 네이버 원목록 참고값/기존 인포맥스 검토값 경로다. 최신 DART 표 확보가 전체 검색 ROE·성장률·PER 갱신으로 자동 연결되지 않는다. 기간·연결기준·지배주주/전체순익·주식수·TTM을 정한 공통 지표 계층이 필요하다. 임의 비율 재계산을 먼저 적용하면 안 된다.
2. **장후 종가·최신성.** 당일 장 종료 및 원천 완료 상태를 확인해 같은 날 완료 일봉을 반영하고, 오래된 종목별 기준일·부분실패·재시도 상태를 구분해야 한다. 현재 자동 완료 확인은 당일 재확인 제한도 있어 원천 지연·정정 재확인 정책을 점검할 필요가 있다.
3. **가격 출처 대조.** [스탁이지 SK하이닉스 공개 요약](https://stockeasy.intellio.kr/stock-analysis/stock-info/000660)은 2026-10-01 종가 1,831,000원·RS96, 우리 네이버 KRX 조정 이력은 같은 날짜 종가 1,828,000원·자체RS 약98이다. 종가 차이는 3,000원(스탁이지 대비 약0.16%). 거래시장·시각·조정·오류 원인을 아직 확정하지 않았다. RS 차이는 모집단 차이로도 생길 수 있다. 스탁이지 52주 고가 2,987,000원과 우리 최고종가 2,919,000원은 고가/종가 정의가 달라 직접 오류 비교하지 않는다.
4. **모집단·시장 환경.** 우리 RS는 같은 거래소의 저장 유효 기업 내 순위이며 스탁이지 전체 종목 기준과 다르다. 단기 RS·시총가중 섹터RS·시장 폭·분산일/후속상승일·수급 및 테마 자금 흐름은 공통 시장판단으로 완성되지 않았다. 스탁이지 수치를 가져와 대체하지 말고 정의와 이력 범위를 먼저 확정해야 한다.
5. **기업 목록 갱신.** 일봉 수집과 최신 가격 조회가 원목록 신규 기업·상장폐지·산업 분류·네이버 참고 재무값을 전부 갱신하는 구조가 아니다. 원목록 주기 갱신과 변경 이력, 원천 삭제 시 관심/보유 기록 보존이 필요하다.
6. **분석 폭.** 스탁이지는 전망치·리포트·뉴스·공시·수급·ETF를 연결한다. 우리 쪽은 검증된 실적/추세가 중심이며 미래 이익 추정치와 컨센서스 변화, 뉴스 중요도 연결이 제한적이다. 전부 복제하기보다 성장률·이익 질·시장/업종 강도를 우선해야 한다.
7. **추천 운영·접속·성능.** 월간 성장형 추천의 운영 기준은 정했지만 실제 월간 추천안·변경 이력·독립 자동 생성은 미완성이다. 모바일 배치는 확인했으나 접속은 127.0.0.1 로컬 전용이다. 이전 점검의 첫 계산 수초 지연도 후속 최적화 대상이며 이번에는 속도 벤치마크를 다시 하지 않았다.

권장 순서는 재무 확보/공통 지표 → 당일 장후 완료/최신성 → 가격 기준 대조 → 단기·섹터 RS와 시장 환경 → 추천 기록이다. 사용자가 이미 선택한 일간 중심·수동 최신 제공가격·간단한 화면 원칙을 유지한다. 실시간 공급자 추가는 데이터 정확성 확보 후의 별도 선택이다.
