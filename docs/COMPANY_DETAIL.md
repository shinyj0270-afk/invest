# 검토 상세분석

## 화면

통합 대시보드에서 **검토 상세분석**을 연다. 삼성전자·SK하이닉스·현대차 등 검토 자료가 연결된 기업을 선택한다. 조건검색 결과와 간단 분석의 상세분석 버튼도 같은 화면으로 연결된다.

2026-10-01에 사용자가 열어 둔 Edge의 스탁이지 로그인 후 [SK하이닉스 종목정보](https://stockeasy.intellio.kr/stock-analysis/stock-info/000660)를 직접 확인했다. 요약·사업·재무·실적·전망·밸류에이션·소식 **6개 탭**과 종목 상단, 카드·차트·표의 배치를 참고해 자체 코드로 구현했다. 원 사이트의 코드·이미지·로그인 정보는 가져오지 않는다.

| 탭 | 연결한 기능 | 추가 원자료가 필요한 영역 |
|---|---|---|
| 요약 | 일·주·월 주가/거래량, MA·BB·ENV, 기간 선택·확장, 요약 항목 설정, 재무 추이, 관심목록 | EPS 이력·전망, 평가등급, 증권사 목표가 |
| 사업 | 저장된 종목 분류, 실적·매출 추이, 영업/순이익률 | 사업 설명·주식수·외국인 지분율, 수주잔고, 사업부 매출, 원가·판관비 |
| 재무 | TTM·연간·분기, 연결·별도, 수익성·자산/부채/자본, 손익/재무상태표, 정렬·행별 추세, EBITDA 입력 | 비용/세금 상세 계정, ROE 분해, 현금흐름, 실제 DPS |
| 실적·전망 | 저장 분기 매출·영업이익 실적 | 발표 전 전망치, 전망 수정 이력, 리포트·목표가 |
| 밸류에이션 | 기존 검증 PER/PBR와 근거, 배당 화면 이동, 동일 산업·기간·기준 표본 비교 | 과거 주당값·배수 분포, 밴드·RIM·시가총액 변화 분해 |
| 소식 | 저장 공시·뉴스 필터, 최신순 목록, 선택 항목의 출처·원문 링크 | 리포트 메타데이터, 내부자 거래 원자료 |

미연결 영역도 해당 탭의 위치에 표시한다. 데이터가 없으면 `—` 또는 `자료 미연결`이며 0·가상의 전망치·평가등급으로 대체하지 않는다. 실제 PER/PBR는 검토 계약에서 검증되지 않아 현재 회사 PC 상세 화면에 `—`다. 네이버의 참고 수치는 기존 간단 분석에서 별도 출처로 확인할 수 있다. 화면 구성을 맞춘 것이며 유료 서비스의 전체 데이터 기능이 연결된 것은 아니다.

## 가격과 재무 기준

- 가격: 검토 스냅샷 기준일까지의 저장 이력만 사용한다. 공개 캐시의 같은 종목 코드·확정 여부·거래소·가격 수정 기준·날짜 순서/중복을 확인한다. 유효한 공개 일봉이 있으면 상단과 차트에 동일 수정종가와 날짜를 표시한다. 시가총액 등 검토 수치의 기존 기준은 보존한다.
- 시가·고가·저가가 없거나 OHLC 범위가 잘못되면 종가 선으로 표시한다. 주/월은 첫 시가·최고 고가·최저 저가·마지막 종가·거래량 합계이며 OHLC가 하나라도 없으면 해당 구간의 캔들을 만들지 않는다. 관측 기간의 마지막 날짜를 표시한다.
- MA: 선택한 일/주/월 **5·20·60구간** 평균. BB: 20구간 평균 ± 2 표준편차(모집단). ENV: 20구간 평균 ± 5%. 전체 선행 이력으로 계산한 뒤 선택 기간을 표시한다.
- 상대가격 선: 같은 날짜의 종가/시장지수를 시작값 100으로 정규화한다. 순위형 RS 점수와 다르다. 지수 날짜가 없으면 선을 끊는다. 52주 종가 범위는 범위 전체와 기준일 및 지수 관측일 일치가 필요하다.
- 재무: 기존 재무표의 종목 식별·출처·회계기준·기간·공개일/중복 확인을 재사용한다. 입력 KRW를 억원으로 표시한다. **TTM은 정확히 연속된 4개 단독분기의 손익 합계**, 자산·부채·자본·차입금은 마지막 기말 잔액이다. 결측 분기를 0으로 처리하지 않는다. 누적 실적을 단독분기로 간주하지 않는다. 연간은 확인된 연간 자료 또는 해당 연도의 네 분기가 모두 있는 경우만 표시한다.
- 현재 실제 3사의 2025-09/12·2026-03/06 CFS 단독분기와 기존 가격 캐시를 사용한다. 연간 실적과 현금흐름 원자료는 미연결이다. 공개일 미확인 자료는 과거 시점 검증용이 아니다. 총차입금의 혼합 출처·계정 범위 불확실성은 표의 `*`와 안내에 보존한다.

## 입력과 저장

EBITDA는 기존 입력 도구를 공유한다. 재무 탭 아래 주요 재무지표에서 직접 입력하거나 영업이익 + 감가상각비 + 무형자산상각비로 계산한다. 간단 분석과 상세분석에서 같은 기업·기간·연결/별도·단독분기/연간 입력을 사용한다. 입력은 DB/원자료/포트폴리오 판단값에 쓰지 않는다. 두 PC 간에는 EBITDA JSON을 따로 저장/불러오기한다.

별표는 기존 관심목록을 공유한다. 상세 탭·차트 기간·표 기준·요약 표시 항목과 기업 선택은 현재 탭의 sessionStorage에 저장한다. 기업 복원은 코드·명칭·시장까지 일치해야 한다. live 갱신 때는 기존 보유·조건·관심목록·EBITDA와 상세 화면 설정을 함께 인계한다. 보관이 제한된 브라우저에서는 입력 JSON을 사용한다.

## 검증

새 단위 검사는 네 분기 연속성·기말 잔액·회계기준 분리·미완성 연간·수기 EBITDA·주월 OHLC 집계·지표 계산·지수 결측을 확인한다. 브라우저 검사는 여섯 탭·종목 전환·EBITDA/관심목록 공유·필터·설정 복원·기존 조건검색 연결·키보드·390px·외부 요청 없음을 확인한다. 실제 저장 HTML에서도 같은 검사를 수행하며 가상의 입력값은 캡처 전에 삭제한다.
