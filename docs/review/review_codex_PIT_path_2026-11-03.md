# Codex 교차 검토 — PIT 자료 경로(Q01~Q03) 설계 (읽기 전용 검토 기록)

작성: 2026-11-03. 검토자: Codex(독립 검토, 읽기 전용: 파일 수정·서버·데이터 접근·테스트 실행 없음). 대상: 로컬 main `f2bc84b`와 `research_Q01~Q03`. 이 문서는 **모델 검토 결과의 요약**이며 채택된 설계가 아니다. 사용자 승인 없이 구현하지 않는다.

Claude Code가 직접 코드에서 다시 확인한 항목(4건): ① `investment/dart_statements.py:402`·`investment/fiscal_contract.py:23`은 `available_at`이 접수번호 날짜와 같아야 통과시킨다. ② `investment/financial_update_policy.py:34`는 7% 이상 변화를 중대한 변경으로 본다. ③ `investment/market_history.py`의 `ADJUSTMENT_NOTE`는 총수익률이 아니고 거래량 보정을 가정하지 않는다고 명시한다. ④ `investment/leader_strategy.py:31-35`는 저장 거래대금이 있으면 쓰되 VWAP은 종가×거래량을 쓴다. 나머지는 Codex의 추론이며 재확인하지 않았다. 외부 사실(OpenDART·KRX 문서)은 Codex가 공식 안내 페이지로 확인했다고 보고했으나 Claude Code는 직접 열어보지 않았다.

## 핵심 결론

작은 **접수번호 단위 연간 재무 어댑터**부터 시작하면 된다. KRX 이력, 완전한 권리조정 엔진, 2008년 복원은 연간 재무 행을 들이기 위한 선행 조건이 아니다.

## 최소 경로 (제안, 미수행)

1. **좁은 파일럿과 접근 경계**: 12월 결산·원화·연결(CFS)인 국내 일반 기업 3곳, 4개 연속 사업연도. ETF는 제외. 파일럿은 현재 생존 기업의 회사 단위 복원이며 과거 시장 표본이 아니다. 사용자만 할 일: OpenDART 키 신청, 약관·보존 조건 확인. 점검: 생존 기업이 과거 모집단처럼 쓰이지 않게 범위를 명시하고, 나중에 상장폐지된 기업 하나를 식별 점검에 포함.
2. **접수번호 목록 → 원본 보존**: 정정 포함 연간 공시를 열거하고 `rcept_no`·`rcept_dt`·보고서 종류·결산일·연결/별도·조회 시각·산출물 해시를 기록. 접수번호별 XBRL을 받는다. 점검: 페이지 누락, 원본 대신 정정본, 같은 접수번호 아래 바뀐 바이트. 옛 산출물을 확보할 수 없으면 "과거 버전 없음"으로 표시하고 오늘 값으로 만들어내지 않는다.
3. **접수일과 사용 가능일 분리**: `rcept_dt`는 그대로 두고 연구용 `available_at`은 접수일 **이후 첫 거래일**(정책 버전 명시)로 둔다. 보수적 적격 기준이지 실제 공개 시각이 아니다. 개정 묶음은 회사·보고기간·보고서 종류·연결/별도 기준. 점검: 접수 당일 장 마감 사용, 휴일 처리, 미래 정정의 소급 적용, 나중 보고서의 재작성 비교값에 이전 연도 날짜 부여.
4. **하나의 회계 계약으로 정규화**: 연간 전체 기간 값만 받고 통화·단위·계정 출처를 보존. 연결·별도를 섞지 않는다. 점검: 4분기 단독값과 연간 혼동, 비교 열 오선택, 비12월 결산 강제 변환, 전환 단기 사업연도. Q에는 이자부 부채·현금·실효세율·`tax_verified`가 필요하고, 부족하면 Q만 결측으로 두며 매출·영업현금흐름(G/C)은 채울 수 있다.
5. **선택된 버전을 연구용 `annual`로 투영**: 접수번호 보관소와 화면용 적용 캐시를 분리하고 기준일마다 적격 사실만 채운 뒤 `analyze()`를 호출. 점검: 미래 정정이 이전 기준일 결과를 바꾸면 안 되고 늦은 기준일은 1% 정정도 반영해야 한다. 현재 화면 정책은 7% 미만 변경을 미룰 수 있고 V/B는 시점 표시가 없는 `metrics`를 읽으므로 **연간 적재만으로 완전한 PIT 품질 점수가 되지는 않는다.**
6. **재무 재현을 먼저 수용, 가격 의존 주장은 따로**: 모든 연간 값이 산출물까지 추적되고 정정 재생이 되면 수용. 오늘의 수정주가가 과거 가치·거래량·체결가를 오염하지 않는지(분할 구간 원시 가격 대조, EPS 주식수 기준, 반복 다운로드 비교)는 가격 근거를 쓸 때 별도로 검증.

## 아직 만들지 않을 것
