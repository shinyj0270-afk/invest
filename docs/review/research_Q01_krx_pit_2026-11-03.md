## 우리 시스템에 대한 해석 [AI 해석]

1. 현재 종목 목록을 과거에 소급하면 구체적으로 이런 누락이 생긴다. KIND 기록상 2008-10-10에 국민은행이 지주회사 완전자회사화로 폐지됐고, NHN은 2008-11-28에 폐지된 뒤 NAVER로 이어진다. 현재 목록에서 출발하면 2008년의 이 종목들이 빠지거나 다른 이름으로만 보인다. 이 두 건은 확인된 사실이고, 이것이 시스템 지표를 얼마나 바꾸는지는 측정하지 않았다.
2. "폐지"에는 부실 폐지만 있는 것이 아니다. 합병·이전상장·완전자회사화·해산이 섞여 있으므로 폐지사유로 분류하지 않고 전부 부실 종목으로 처리하면 위험이 과대평가될 수 있다. 반대로 폐지 종목을 빼면 생존편향이 생긴다. 사유별 규칙이 필요하다.
3. 가장 큰 구조적 제약은 날짜 하한과 약관이다. 2008년 일별 시총·상장주식수는 공식 OPEN API로 얻을 수 없고(F1), 웹 화면 자동 수집은 약관상 금지(F6)이며, OPEN API 결과의 보존·제3자 제공도 제한된다(F5). 따라서 2008 국면은 현재 확인된 공식 경로만으로는 일별 PIT 시총 재구성이 불가능하다고 보는 것이 안전하다. 경로가 있을 가능성(유료 상품 등)은 확인하지 못했다.
4. 보존 관련 약관 문구(F5 제11조③ "이용계약 종료 후 받은 정보 이용 불가")가 로컬 DB에 저장한 데이터의 장기 보존·재검증과 충돌하는지는 법적 해석이 필요하다. 이번 조사에서 결론을 내지 않았다.

## 아직 검증할 가설

- H1: KRX OPEN API 일별매매정보의 과거 일자(예: 2020-03-31)에는 그 이후 폐지된 종목이 포함된다.
- H2: KIND 상장폐지현황은 거래소 상장 이래 전체 폐지를 포함한다(하한 연도). 2008년 35건이 당시 전체인지 별도 대조가 필요하다.
- H3: KIND "비고"·KRX "이전상장후 종목코드"만으로 합병·이전상장 후 종목 연속성을 건별로 복원할 수 있다.
- H4: DART corp_code는 합병·폐지·상호변경 후에도 안정적인 식별자이며 corpCode.xml에 폐지사가 남아 있다.

## 채택 전 최소 데이터·테스트

1. T1 (H2): 2008·2020·2022 각 연도의 KIND 폐지 목록 건수를 연도별로 기록하고, 이미 알려진 폐지 사례 3건 이상을 목록에서 찾아 대조한다. 스팩·리츠·경매 목적 회사 제외 규칙을 문서화한다.
2. T2 (H1): 사용자가 OPEN API 인증키를 직접 신청한 뒤, 2020-03-31 일별매매정보 1회 호출로 이후 폐지 종목 포함 여부를 확인한다. 키 신청과 약관 동의는 사용자 행위다. 호출 한도 10,000회/일을 지킨다.
3. T3 (H3): 이전상장·합병 사례(NHN→NAVER 등) 3건에 대해 KIND 변경상장 공시와 KRX 코드 열로 전후 코드를 연결해 본다.
4. T4 (H4): 폐지된 기업 1~2곳의 corp_code 조회 가능 여부와 corpCode.xml 포함 여부를 확인한다(OpenDART 키 필요).
5. T5: 2008 일별 시가총액·상장주식수 확보 경로(KRX 마켓데이터 유료 상품의 시작연도·가격·재배포 조건)를 KRX 문의로 확인한다. 공문이 필요하면 사용자가 보낸다.

## 필요 입력 필드 (재구성용 최소 스키마 제안)

종목 식별: 표준코드(ISU_CD)·단축코드·DART corp_code·종목명(기간별)·시장구분·증권구분. 이벤트: 상장일·폐지일·폐지사유(분류 코드)·이전상장후 코드·승계사. 일별: 기준일자·종가·거래량·거래대금·시가총액·상장주식수. 주식수 이벤트: 상장방식(추가·변경·신규·재상장)·변경일·변경 후 주식수. 출처 메타: 출처 URL·조회일·약관 버전·접수일자(날짜 단위).

## 기존 구현과의 차이와 도입하지 않을 이유

- 기존: 현재 저장 유니버스·가격을 조합해 소급 적용([redteam](redteam_2026-11-03.md) R03/R04). 이번 조사로 폐지 목록 자체는 공식 경로에서 확인 가능함을 확인했다.
- 도입하지 않을 이유: ①2008 일별 시총·주식수 확인된 공식 경로 없음, ②자동 수집 약관 금지, ③OPEN API 결과의 제3자 제공 금지·종료 후 이용 제한, ④폐지 정산가 미확인. 위 T1~T5로 해소되기 전에는 소급 보정을 지표에 반영하지 않는다.
