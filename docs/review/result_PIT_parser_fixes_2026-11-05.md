## 미해결·사용자 검토 필요
1. **수기 값 검토**: 리스부채 18개와 한국가스공사 차입금 6개(`COMPANY_NOTE_FACTS`), LG화학 포함 총액 6개(`COMPANY_BORROWINGS_INCLUDE_LEASE`)는 Codex가 주석에서 읽은 값이다. Claude는 원문 대조를 독립적으로 하지 않았다. S-Oil·효성 수기 값과 같이 사용자 검토 대상.
2. **LG화학 FY2025 이중 계상 여부 미확인**: FY2025는 리스(1,014,972백만원)가 면에서 읽히는데, 이때 차입금이 리스를 포함하는지 확인하지 않았다. 포함이면 차입금 33.8조원 대비 약 3% 중복이다.
3. **한국가스공사 FY2025**: 차입금·리스 수기 값 없음. FY2025 본표가 같은 `금융부채` 구조인지 별도 조사가 필요하다.
4. **한화솔루션 FY2025 원본 접수번호**: 목록에 원본이 없고 `첨부추가`·`기재정정`만 있다. 확인하려면 새 외부 요청이 필요하다.
5. **수기 값은 접수번호 키가 없다**: 같은 회사연도의 정정본에도 주입될 수 있다. 장기적으로 접수번호/SHA 조건부로 바꾸는 설계가 필요하다.
6. Codex 보고서 지적: `read_accounts`가 77줄(50줄 규칙 초과, 기존 구조 유지). 분리는 별도 작업.
7. `PARSER_VERSION` 증분과 기존 저장 레코드 재생성 정책은 정하지 않았다.
