남은 131개 중 125개를 테스트로 만들었다: `tests/test_sweep_g1.py`~`g4.py`(129개 테스트, 변이 id를 테스트 이름에 포함). 구현은 Codex(`gpt-6-astra`/medium) 4개 작업이 파일 단위 그룹으로 나눠 격리 복사본에서 작성했고, Claude Code가 워크트리에서 `mutcheck`(원본 통과·변이 실패)를 독립적으로 다시 실행해 125개 모두 KILLED를 확인했다. 새 테스트만 순서대로·역순으로 129개, 비UI 전체 1291개(스킵 3)가 통과했고 운영 DB 해시는 전후 동일했다.

남은 6개는 테스트로 만들지 않았다(Codex 판단, 코드 읽기로 동의했으나 모두 독립 증명한 것은 아니다):
