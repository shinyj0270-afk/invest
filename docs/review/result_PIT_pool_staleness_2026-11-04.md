# PIT 풀 구성: 신선도(상장폐지) 규칙과 이전 결과의 정정 (2026-11-04)

범위: 사용자 지시 "다음"(상장폐지 종목을 기준일 풀에서 제외하는 규칙). 외부 요청 0건.

## 1. 규칙(제안)
- `pit_factors.pit_scores(..., max_staleness_days=460)`: 기준일에 **최신 연간 기간이 기준일보다 460일(약 15개월: 1년 + 연간보고서 제출 기한까지의 공백) 넘게 오래된 회사는 "그날 현재 데이터가 없는 회사"(예: 상장폐지)로 보고** 모든 풀에서 제외한다. 그 회사의 `S_pit_QGCB`는 None, 사유는 `stale_period`, 결과에 `stale=True`와 `latest_period`가 붙는다. `None`이면 규칙을 끈다.
- 별도 상장·폐지일 자료 없이 PIT 데이터만으로 판단한다. 한계: 폐지 직후에도 한동안(최대 460일)은 풀에 남을 수 있고, 제출이 늦은 회사를 잘못 제외할 수 있다. 기간은 매개변수다.
- 경계는 포함(460일까지 유효, 461일째부터 제외). 보이는 연간 행이 하나도 없는 회사는 신선도 문제가 아니라 요인 누락이다.
- 검증: 테스트 먼저(신선도 7개), 변이 14개 모두 검출, 비-UI 전체 1525개 통과. 구현은 Codex 없이 직접(기존 모듈에 규칙 추가).

## 2. 실제 효과와 이전 결과의 정정
- 기준일 2026-11-03에서 동아타이어공업은 최신 기간이 2023-12-31(약 34개월 전)이라 제외되고, 삼성중공업·롯데케미칼·RFHIC·효성중공업은 2025-12-31(약 10개월 전)이라 포함된다.
- **정정**: 직전 단계에서 보고한 첫 `S_pit_GC` 점수(RFHIC 78.9, 삼성중공업 63.3, 효성중공업 50.0, 동아타이어공업 47.8, 롯데케미칼 10.0)는 **2024년에 상장폐지된 동아타이어공업을 풀에 넣어 풀 5개를 채운 것**이었다. 살아 있는 회사만 쓰면 풀이 4개라 `S_pit_GC`도 `S_pit_QGCB`도 **아직 어느 회사에서도 계산되지 않는다**(`pool_too_small`). 그 점수표는 규칙을 적용하기 전의 참고값이며 쓰면 안 된다.
- G·C 값 자체(회사별 성장·현금창출 지표)는 그대로 유효하다. 풀 크기만 문제다.

## 3. 다음 후보
- 풀을 5개 이상으로 키우려면 **회사를 더 추가**해야 한다(새 외부 요청, 요청 목록 승인 필요). 현재 계정 확보율로는 Q·B까지 계산되는 회사가 더 적으므로, 점수를 목표로 한다면 Q·B가 잘 읽히는 대형 비금융 제조·에너지 회사 위주로 고르는 것이 효율적이다.
- 법인세 예외 규칙 확정, 효성중공업 리스부채와 FY2023 차입금 점검.
- 임시 폴더 `credit/_tmp_pitxml_tags`, `_tmp_pitmetrics`, `_tmp_pitfactors`는 사용자가 삭제해야 한다.
