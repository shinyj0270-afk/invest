# 재무구조·재무수치 개념 기준: NICE신용평가 「재무위험 평가」 (2021.12.24, 적용일 2021.12.27)

목적: PIT 파이프라인이 다루는 재무구조와 재무수치(차입금, EBITDA, 현금흐름, 부채비율 등)의 **정의를 이 자료에 맞춘다**. 사용자 지시(2026-11-04): "재무구조 및 각 재무수치에 대한 개념은 이 자료의 내용을 기반으로 해줘".

## 0. 출처 취급
- 원문은 NICE신용평가의 신용평가 일반론(기초 4) 24쪽이다. 원문 첫머리의 유의사항이 무단 전재·인용·가공·재배포를 금지하므로 **PDF는 저장소에 넣지 않고** 이 문서는 내용을 요약한 적용 메모다. 쪽 번호(p.N)만 참조한다.
- 원문 스스로 "예시한 재무비율은 일부이며 참고 목적"이라고 밝히고(p.3), 정성 판단이 함께 쓰인다고 한다. **임계값이나 등급 매핑은 원문에 없다.** 따라서 이 문서는 정의의 기준이지 점수 기준표가 아니다.
- 원문은 채권자 관점의 상환능력 분석이다. 주식 품질 점수에 쓰는 것은 이 시스템의 해석이며 원문이 권하는 용도가 아니다.

## 1. 재무위험의 틀 (p.3)
- 재무위험은 필요한 자본을 어떻게 조달하느냐에서 생기는 위험, 특히 위험자본인 차입금을 쓰는 데서 생기는 위험이다. 총자본 중 차입금 비중이 클수록 커진다.
- 분석 범주 다섯 가지: 재무·회계정책, 수익성, 현금흐름의 적정성, 재무구조·자산내용, 재무적 융통성. 앞의 세 범주(수익성, 현금흐름, 재무구조)가 주로 정량 지표이고 재무정책·융통성은 정성이다.
- 시간 범위는 과거 3~5년(최소 한 경기순환)과 미래를 함께 본다.
- 이 시스템의 PIT 연간 재무(연 1회 사업보고서)는 정량 3개 범주에 해당하고, 정책·융통성은 범위 밖이다.

## 2. 자기자본과 타인자본 (p.16~17)
- 자기자본: 상환 부담이 없고, 만기가 없고, 청산 때 채권자의 완충이 된다. 타인자본: 만기와 원금 상환 부담이 있고, 이자를 정기적으로 내야 하며, 청산 때 선순위다.
- 쟁점 항목과 처리:

| 항목 | 원문의 처리 |
|---|---|
| 전환사채 | 전환 전까지 타인자본(차입금) |
| 상환우선주 | 회계상 자본이어도 고정배당·만기가 있어 차입금과 비슷, 분석 목적으로 차입금으로 보기도 함 |
| 하이브리드(영구채, 전환상환우선주) | 회계상 자본이지만 만기 영구성, 이자·배당 지급의 임의성, 후순위성 세 가지로 자본성을 판단 |
| 풋 권리·고정배당이 있는 보통주 | 차입금으로 볼 수 있음 |
| 이연법인세부채 | 쟁점으로 언급만 하고 **원문에 처리 기준이 없음** |

- 자기자본의 구성은 자본잉여금보다 이익잉여금의 추이가 중요하다(수익성과 배당정책을 반영).

## 3. 차입금 (p.18, p.21~22)
- 타인자본 = 이자 부담이 명시된 **차입금** + 영업·투자활동에서 생기는 비금융부채(매입채무, 미지급금, 선수금 등).
- 재무상태표의 차입금 구성: 단기차입금, 유동성장기차입금, 장기차입금, 회사채, **리스부채**. 단기성차입금에는 유동성사채, 유동성리스부채도 들어간다(p.22).
- 장부 밖 차입금: 매출채권 할인, 자산유동화증권, 지급보증·담보제공 등 우발채무(p.21). K-IFRS에서는 매출채권 할인이 차입거래로 회계처리되므로 K-IFRS 기업에서는 별도 검토 대상이 아니다.
- 순차입금 = 총차입금 − 현금성자산(p.4). 현금성자산은 현금및현금등가물, 단기금융상품, 유동금융자산을 포함하되 용도가 묶인 예금(에스크로, 담보성 예금, 계열사 지원성 예금 등)은 유동성이 낮은 것으로 본다(p.19).
- 비금융부채는 규모의 적정성을 본다. 결제 기간이 지나치게 길면 차입금으로 바뀔 수 있다(p.18~19).

## 4. 수치별 정의

### 4.1 수익성 (p.8~9)
| 지표 | 정의 | 메모 |
|---|---|---|
| 매출액영업이익률 | 영업이익 / 매출액 | K-IFRS 개정 이후 공시 영업이익과 같은 개념 |
| EBITDA | 영업이익 + 유·무형자산상각비(실무 정의) | 이론상은 이자·세금 차감 전 이익에 상각비를 더한 값 |
| EBITDA 마진율 | EBITDA / 매출액 | 감가상각정책이 다른 기업 간 비교용 |
| 투하자본수익률 | 세후순영업이익 / 투하자본 | 세후순영업이익 = 영업이익 × (1 − 유효법인세율). 관계기업주식 등 비영업자산은 투하자본에서 제외 |
| 총자산영업이익률 | 영업이익 / 총자산 | 비영업자산 비중이 크면 비교성 저하 |
| 자기자본순이익률 | 순이익 / 자기자본 | 영업이익 기반 지표와 달리 타인자본의 영향을 받음 |
| 기타 | 세전계속사업이익 / 매출액, 손익활동현금흐름 / 매출액, 잉여현금흐름 / 매출액 | |

지속가능성 원칙(p.7): 일회성 손익(자산 처분·평가손익, 손상차손·환입, 충당금 환입, 법인세 환급·추납, 채무면제이익, 전기오류수정, 중단사업손익 등)은 조정해서 본다. 영업 계정 안에 섞여 있는 경우도 있다.

### 4.2 금융비용부담 (p.10~11)
- 금융비용 = 이자비용(차입금·리스부채 이자, 현재가치할인차금·사채할인발행차금 상각액) + 보증수수료 + 매출채권처분손실 + 차입금으로 처리된 상환우선주 배당 + **손익계산서에 비용화되지 않은 자본화 이자**.
- 지표: 영업이익 / 금융비용, EBITDA / 금융비용, (세전계속사업이익 + 금융비용) / 금융비용, (손익활동현금흐름 + 금융비용) / 금융비용, (영업활동현금흐름 + 금융비용) / 금융비용, (잉여현금흐름 + 금융비용) / 금융비용. 앞쪽일수록 발생주의 이익 기반, 뒤쪽일수록 현금 기반이다. 손익활동현금흐름 이후 지표만 법인세를 낸 뒤의 값이다.

### 4.3 현금흐름 체계 (p.11~14)
EBITDA → (± 비현금항목) → **손익활동현금흐름(GCF, FFO)** → (± 운전자금, 기타) → **영업활동현금흐름(OCF)** → (− 자본적지출) → **잉여현금흐름(FCF)** → (− 배당) → **처분가능현금흐름(DCF)** → (± 비영업자산 순투자) → 자금조달활동 전 현금흐름 → (± 외부조달·상환) → 현금 증감.

- GCF: 당기순이익에서 상각비, 이연법인세, 처분·평가손익, 외화환산손익, 지분법손익 등 비현금 항목을 조정한 값. 운전자금 변동을 빼고 기본 창출력을 볼 때 쓴다.
- OCF: 운전자금 투자는 반영하고 유무형자산 투자는 반영하기 전. 구조조정 퇴직금, 대규모 자산 처분 법인세 같은 일회성의 영향을 판단해야 한다.
- FCF: OCF에서 **경쟁지위 유지에 필수적인** 유무형자산 투자를 뺀 값. 업종에 따라 연구개발(IT·제약), 수주 유지 투자(건설), 임차보증금(일부 업종)도 차감 대상이다. 투자활동의 자산 처분 수입은 반복적이지 않으므로 보통 반영하지 않는다(렌탈·해운처럼 반복되는 업종 예외).
- 리스(p.14): 설비를 사는 기업은 투자가 FCF에 반영되지만 리스를 쓰는 기업은 리스부채 상환이 재무활동이라 FCF에 반영되지 않는다. 그래서 **리스를 많이 쓰는 기업은 FCF에서 리스부채 상환액을 뺀 값을 실질 잉여현금으로 본다.**
- DCF: 양(+)이면 내부 상환재원이 생기는 것, 음(-)이면 정상적인 방법으로는 차입금을 줄일 수 없다는 뜻.
- 매출채권 할인, 자산유동화, 이자 자본화, 개발비 자산화는 OCF·FCF의 기업 간 비교성을 떨어뜨린다(p.13, p.16).

### 4.4 현금흐름 비율 (p.15)
| 지표 | 정의 |
|---|---|
| 차입금 / EBITDA | 총차입금 / EBITDA, 순차입금 / EBITDA |
| OCF / 총차입금 | 영업활동현금흐름 / 총차입금 × 100 |
| GCF / 총차입금 | 운전자금 변동이 큰 업종에서 대안 |
| FCF / 총차입금 | 필수 투자를 뺀 상환재원 기준 |
| 단기성차입금상환계수 | (FCF + 금융비용) / (금융비용 + 만기도래차입금) |
| 투자소요조달능력 | OCF / 자본적지출, GCF / 자본적지출 |

원문의 강조점: 단일 비율에 의존하지 말고 여러 비율을 같이 본다. 사업경쟁력이 좋고 구조가 양호한 기업은 GCF 대비 비율을, 차입금 절대 규모가 문제인 기업은 FCF 대비 비율을 중시한다(p.16).

### 4.5 재무구조 비율 (p.22)
| 지표 | 정의 |
|---|---|
| 부채비율 | 총부채 / 자기자본 × 100 |
| 차입금의존도 | 총차입금 / 총자산 × 100 |
| 차입금 / (차입금 + 자기자본) | 자금조달 구성 |
| 단기성차입금비율 | 단기성차입금 / 총차입금 × 100 |
| 고정장기적합률 | 고정자산 / (자기자본 + 고정부채) × 100, 100% 초과 시 유동부채로 고정자산을 조달했다는 뜻 |

모두 자산 재평가, 감가상각정책, 부외 항목의 영향을 받는다.

## 5. 지금 시스템과의 대응

현재 PIT 파서가 만드는 필드는 `revenue`, `operating_profit`, `ocf`, `equity`, `cash` 다섯 개다(`balance_debt`는 만들지 않는다). 부분 점수는 두 지표다.

| 시스템 값 | 원문 개념과의 관계 |
|---|---|
| revenue | 매출액. 일치 |
| operating_profit | 공시 영업이익. 원문의 EBIT와 같은 개념이지만 **일회성 항목 조정은 하지 않음**(원문은 조정을 권함) |
| ocf | 연결 현금흐름표의 영업활동현금흐름 보고값. 원문 정의와 같지만 이자·법인세 분류, 자본화, 유동화에 따른 비교성 저하 가능 |
| equity | 자본총계. 하이브리드·상환우선주 등 **자본성 조정은 하지 않음** |
| cash | `현금및현금성자산`만. 원문의 순차입금용 현금성자산(단기금융상품, 유동금융자산 포함, 제한 예금 제외)보다 **좁다** |
| G (3년 매출 CAGR) | **원문에 없는 자체 지표.** 원문은 추세·변동성·안정성을 본다는 관점만 제시 |
| C (OCF/매출 중앙값) | **원문에 없는 자체 지표.** 가장 가까운 것은 기타 수익성의 손익활동현금흐름/매출, 잉여현금흐름/매출. 원문이 OCF를 쓰는 비율은 OCF/총차입금, 이자보상 계열 |

즉 지금 계산되는 G·C는 이 자료의 재무위험 지표가 아니라 시스템 자체 정의다. 이름이나 설명에서 NICE 지표로 오해되지 않도록 해야 한다.

## 6. 추가로 필요한 계정과 추출 단계

원문의 재무구조·상환능력 지표를 만들려면 현재 다섯 개로는 부족하다.

**A단계: 재무제표 본문만으로 가능(파서 확장 대상)**

| 계정 | 쓰임 |
|---|---|
| 자산총계, 부채총계 | 부채비율, 차입금의존도, 총자산영업이익률 |
| 단기차입금, 유동성장기차입금, 장기차입금, 사채(유동성 포함), 리스부채(유동·비유동) | 총차입금, 단기성차입금비율, 차입금 계열 비율 |
| 단기금융상품, 유동금융자산 | 순차입금용 현금성자산 |
| 이자비용(금융비용) | 이자보상 계열 |
| 유·무형자산 상각비(현금흐름표 조정 항목) | EBITDA |
| 유·무형자산 취득액(투자활동) | 자본적지출, FCF |
| 배당금 지급(재무활동) | DCF |
| 법인세비용, 법인세차감전계속사업이익, 당기순이익 | 세후 영업이익, ROE |

**B단계: 주석이나 정성 확인이 필요**
부외 차입(매출채권 할인, 지급보증), 전환사채·상환우선주·하이브리드의 구분, 제한 예금, 차입금 만기 구조, 이자 자본화, 리스부채 상환액, 일회성 손익 항목. 이 단계는 자동화가 어렵고 회사별 판단이 들어가므로 PIT 범위에서는 **해당 없음 표시(미확인)**로 두는 것이 안전하다.

계정명이 회사마다 다르고(차입금 항목 이름, 금융비용 표시 위치) 금융업·지주사는 구조가 달라서, A단계도 정확 일치 규칙과 불일치 시 거절(추정 금지)을 지금 파서와 같은 방식으로 유지해야 한다.

## 7. 정의 결정안 (사용자 확인 대기)

원문에 맞춘 기본안이다. 원문에 근거가 없는 항목은 그렇게 표시했다.

1. **총차입금** = 단기차입금 + 유동성장기차입금 + 장기차입금 + 사채(유동성 포함) + 리스부채(유동·비유동). 전환사채는 포함. 상환우선주·하이브리드·부외 차입은 B단계라 기본에서 제외하고 미확인으로 표시.
2. **순차입금** = 총차입금 − 현금성자산. 현금성자산은 현금및현금성자산 + 단기금융상품 + 유동금융자산. 사용 제한 예금은 주석 확인 전까지 구분하지 못하므로 한계로 기록.
3. **EBITDA** = 영업이익 + 유·무형자산상각비(원문의 실무 정의).
4. **FCF** = OCF − (유형자산 취득 + 무형자산 취득). 리스 부채 상환액 차감 여부는 리스 사용이 큰 회사에서만 의미가 있으므로 B단계로 둔다. 자산 처분 수입은 반영하지 않는다.
5. **금융비용** = 손익계산서의 이자비용(리스부채 이자 포함). 보증수수료, 매출채권처분손실, 자본화 이자는 본문에서 못 구하면 미확인.
6. **세금(Q 용도)**: 원문은 세후순영업이익에 유효법인세율을 쓰고, 손익활동현금흐름 이후 지표는 납부 후 기준이다. 유효법인세율은 `법인세비용 / 법인세차감전계속사업이익`로 정하되, 적자·일회성으로 비정상일 때 처리 규칙은 별도 결정이 필요하다. 원문에 이 경우의 기준은 없다.
7. **일회성 조정**은 하지 않고 보고값을 쓴다. 조정하지 않았다는 사실을 지표마다 기록한다.
8. 이연법인세부채는 원문에 처리 기준이 없으므로 **부채에는 포함하되 차입금에는 포함하지 않는다**(제안, 원문 근거 없음).
