## 기준과 저장

- 기존 인포맥스 우선, 동일 계정/기간/단위의1억원 미만 잔차 참고 표시, 분기 신규 공시 우선·일간 정정7% 정책을 유지한다. 확률90%를 실제로 측정했다고 표시하지 않는다.
- 업종 순위는 저장된 유효기업을 대상으로 한 기존 자체 RS다. 현재 시총 가중 수익률이며 과거 투자 가능한 업종지수 수익률과 다르다. 시장·업종을 함께 전달해 다른 시장의 동명 산업을 섞지 않는다. 업종 RS가 없으면 저장 후보 시총 순서라는 표시와 함께 기존 탐색을 제공한다.
- 성장 검색 기본값: 매출YoY≥10%, 영업이익률·ROE≥0%, 부채≤200%, RS≥70, 기본 추세 충족. 돌파 근접은 RS≥70·추세 충족·52주 최고종가 대비5% 이내. 최고종가 접근을 거래량이 확인된 돌파 신호로 단정하지 않는다.
- 저장 검색과 관측 비교는 이 브라우저의 로컬 저장소를 사용하고 실제/가상 모드를 분리한다. 관심목록은 기존 탭 복원·파일 내보내기를 유지한다. 브라우저/PC 사이에 검색과 관측 이력이 자동 동기화되는 기능은 아니다. 저장 실패는 화면에 표시한다.
- 변화 기록은 처음에는 기준값만 저장하며 과거 변화를 합성하지 않는다. 같은 완료 가격일에서는 RS·추세 변화를 만들지 않는다. 휴일/앱 미사용 기간은 마지막 두 실제 관측일로 표시한다. RS 모집단 변화도 점수에 영향을 줄 수 있다. 재무 정정 원문 금액의 변경은 기존 수집 판정에 근거한다. 새 재무 수집일과 공시 발표일을 동일하다고 표시하지 않는다.
- YoY/QoQ는 같은 기준의 실제 인접 기간끼리 계산한다. 전기 값이0·음수 또는 미확보이면 비율을 표시하지 않는다. 연결/별도 혼합 금지, ROE는 연속TTM과 평균자본 기준이다. 산업 분류가 같아도 지주회사 등 사업 구조는 다를 수 있다. 영업이익이 매출보다 큰 경우 수치를 지우지 않고 매출 범위 확인 표시를 붙인다.
- 수집 성공·조회 상태는 공개 재무 캐시/관측본/불완전 기록에서 복원한다. 앞으로의 조회 실패도 기업별 별도 상태 파일에 기록하며 기존 성공 재무를 지우지 않는다. 읽을 수 없거나 없는 기록은 성공으로 바꾸지 않는다.
- 추천의 기존 비중·변경 이유·과거 버전을 재작성하지 않았다. 기존 안에는 현재 날짜의 사업 검토를 별도로 덧붙여 보여주며 새 안에는 작성 당시 검토를 보존한다. 사업 근거 검토 후31일이 지나면 재검토 시기를 표시한다. 신규 종목의 사업 근거가 없더라도 수치 기준 후보를 없애지 않고 사업 검토 필요를 명시한다. 자동 인터넷/LLM 사업 검토를 새로 예약하지 않았다.
- 성과는 기존 정의를 유지한다: 작성 후 첫 완료 거래일 종가 진입, 버전별 고정 비중, 현금수익0, 배당·수수료·세금 제외. 종목 기여도의 합은 모델 수익률과 같다. 아직 진입일 전이거나 가격이 없으면 대기이며 가짜 수익을 만들지 않는다.
