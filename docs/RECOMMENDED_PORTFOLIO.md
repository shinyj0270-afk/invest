# 추천 포트폴리오 운영 기준

## 사용자 결정 · 2026-10-02

추천 포트폴리오는 Codex가 기업 자료와 투자 근거를 검토해 작성한다. 사용자가 후보를 모두 입력해야만 만들어지는 계산 화면을 최종 추천 기능으로 취급하지 않는다. 실제 보유 입력과 추천 목표안을 구분하며 추천 작성으로 보유내역을 덮어쓰지 않는다.

투자성향은 사용자가 **성장형: 변동성을 감수하고 성장성과 상승 추세에 더 집중**으로 선택했다. 기업별 성장 근거와 상승 추세에 더 무게를 두되 수익성·재무 체력·가치평가 자료와 반대 근거를 함께 검토한다. 구체적인 평가 가중치나 손실 허용 수치를 이 선택만으로 확정하지 않는다.

- 구성: 기존 합의인 국내 기업 최대5개와 현금. 구체적인 현금·종목·산업 비중은 사용자 투자성향과 검증된 위험 기준을 확인해 정한다. 기존 화면의 개발용 기본값은 사용자 확정 기준이 아니다.
- 정기 검토: 월1회. 운영 기본안은 월초 첫 거래일에 최신 완료 종가와 당시 이용 가능한 재무·공시로 검토하는 것이다. 매월 반드시 종목을 교체하지 않으며 근거가 유지되면 유지안을 작성한다. 정확한 실행일·예약은 아직 등록하지 않았다.
- 중간 검토: 특별히 편입할 가치가 있다고 판단한 기업이 생기면 월중 조정안을 작성할 수 있다. 단순 가격 상승만으로 편입을 확정하지 않는다. 새 기업의 근거, 기존 구성보다 나은 이유, 줄이거나 교체할 기업 또는 사용할 현금, 변경 후 집중도, 판단을 철회할 조건을 함께 쓴다.
- 월간 기준안과 월중 수정안은 작성일·자료 기준일·이유를 각각 보존한다. 월중 수정으로 최초 월간안이나 실제 보유 기록을 삭제하지 않는다.
- 주식 주문·자동매매·계좌 잔고 조회는 수행하지 않는다. 추천 보고서와 실제 사용자의 실행은 별도다.

## 추천 보고서 형식

1. 대상 월, 작성일, 가격·재무·공시 기준일, 정기/월중 수정 구분.
2. 기업명·코드, 목표 비중, 편입/유지/축소/제외 구분, 현금 비중.
3. 기업별 수익성·재무 체력·가치·성장/추세 근거와 원문 출처.
4. 반대 근거·핵심 위험·추천을 철회하거나 다시 검토할 조건.
5. 이전 추천안과 달라진 점, 월중 수정이면 다음 정기 검토까지 기다리지 않는 이유.

확인하지 못한 수치·기간·회계 기준·뉴스를 추론으로 채우지 않는다. 추천자료가 부족하면 작성 대기 사유를 기록한다. 단순 고정 슬롯 균등배분이나 가상 데이터를 Codex의 실제 추천으로 표시하지 않는다.

## 현재 구현과 다음 단계

2026-10-02 기준으로 저장 재무와 완료 종가를 이용한 월간 추천 초안, 월중 조정 사유, 버전별 모델 성과 화면이 연결돼 있다. 자동 초안은 수치 조건을 적용한 연구용 결과다. 앱이 독립적으로 Codex를 호출해 사업 전망을 조사하는 기능이나 월간 예약은 연결하지 않았다. 개인 추천 기록은 비공개 로컬 저장소에 보존한다.

추천의 재무 최신성 하한은 공시가 모이는 달 이후 적용하는 자체 기준이다. 1~3월은 전년3분기,4~5월은 전년연말,6~8월은 당년1분기,9~11월은 당년반기,12월은 당년3분기부터 허용한다. 이는 법정 제출기한이나 모든 기업의 공시 완료 보장이 아니다. 실제 공시일이 조회일 이후인 자료는 여전히 제외하고, 더 최신의 검증 자료가 있으면 사용한다. 공시 전인 월초에 아직 없는 분기를 요구해 정상 후보가 모두 탈락하던 문제를 수정했다.

다음 보완은 기업의 사업 성장 근거·반대 근거를 직접 검토한 추천 설명, 자료 부족으로 생긴 현금안의 재검토 표시, 월중 변화에 대한 비교 설명이다. 과거 버전은 당시 판단 기록으로 보존한다.
