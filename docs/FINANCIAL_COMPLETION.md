# 미확보 재무자료 보완 · 2026-10-02

> 후속 전체 재검토에서 저장 원문을 실제 재해석하지 않던 복구 경로를 발견해 수정했다. 아래 확보 수는 당시 집계다. 최종 재검토 후 재무1,322/최신반기1,238/연속TTM1,184/미확보49는 같고, 귀속 계정의 검증을 강화해 ROE 가능 기업은1,034→1,010개로 조정한 뒤, 사용자 허용 오차 기준의 명시 계정을 참고 복원해 최종1,016개다. 7,391개 원문 재해석 및 검증 완료. 자세한 수정과 제한은 [대시보드 재검토](DASHBOARD_REVIEW_2026-10-02.md)를 따른다.

## 실제 확보 결과

2026-10-02 로컬 공개 재무 캐시를 같은 탐색 대상 1,371개로 대조했다. 이 집계는 DART 재무 기준이며 기존 인포맥스 수기 검토 자료는 별도로 우선 적용한다.

보완 후 연결 기준 1,152개, 별도 기준 170개다. 재무 저장은 모든 지표의 확보를 의미하지 않는다. 지배계정·과거 분기 등이 부족하면 ROE/TTM은 대기로 남고, 공개 재무상태표에서 범위가 확인된 차입금·사채는 855개다. 전체 총차입금·배당·상각비를 임의 추정하지 않았다.

마지막 추가 조회에서 DART 기업 검색 연결이 응답 없이 종료되는 `RemoteDisconnected` 오류를 직접 확인했다. 남은 49개의 미확보 원인을 모두 ‘공시 없음’으로 단정하지 않는다. 조광피혁(004700) 재시도에서도 같은 연결 오류가 발생했다. 추가 수집의 실패 횟수에는 기존 재무가 있는 기업의 누락 기간 재조회 실패도 포함되므로 49개 미확보 수와 다르다. 공개 연결 회복 후 남은 기업/기간 재조회가 다음 실행 지점이다.

대형 누락 기업을 포함한 실제 삼성SDI·HD한국조선해양·한화에어로스페이스·에코프로·넷마블·원익IPS·동진쎄미켐의 매출/영업이익/순이익과 검색·간단 분석의 공통 지표를 대조했다. 별도 재무는 화면에 OFS로 표시한다. 원문 제출번호·URL·기간·단위·해시는 비공개 저장 보고서에 보존한다. 수집 전후 집계 원본은 로컬 `validation/financial-coverage-before.json`과 `validation/financial-coverage-after.json`이다.

## 수집과 복구

- 탐색 대상은 기존 시총850억원 초과 비금융 후보 범위를 사용한다. 개인 보유·주문·인증설정·DB는 변경하지 않는다.
- 기존 DART 원문은 SHA256과 종목/시장/연결·별도/기간/제출일/대차를 검증한 뒤 재해석한다. 같은 원문 해석 복구는 공급자의 새 공시 정정과 구분한다. 인포맥스 우선, 새 분기 반영 및 같은 기간7% 정정 기준은 유지한다.
- 동일 금액의 매출 총계/하위 반복 표시는 한 번만 사용한다. 서로 다른 금액의 중복은 검증 실패다. 자산합계/부채합계/영업손익/순현금흐름 등 공시 계정명을 보완했다.
- 지배주주 순이익은 같은 표 안의 순차 귀속 쌍과 총 순이익을 대조한다. 계속영업·총포괄손익·주당 이익을 지배순이익으로 쓰지 않는다. 지배자본 항목이 없을 때 확인된 총자본-비지배지분으로 계산할 수 있지만 누락 비지배지분을0으로 두지 않는다.
- 확인 차입금·사채는 공개 재무상태표에 실제 표시된 계정 합계다. 총계와 자식 계정을 중복 합산하지 않으며 불명확한 범위는 계산하지 않는다. 리스·다른 금융부채를 포함한 **전체 총차입금으로 주장하지 않고 별도 이름으로 표시**한다. 기존 검토 총차입금이 있으면 우선한다.
- 매출액 및 기타수익/매출 및 지분법손익은 공시 표시 금액이며 순수 제품 매출과 구성 차이가 있다. 원표의 표시 항목을 설명에 보존한다.
- 연결(CFS) 보고서가 하나도 검증되지 않을 때 별도(OFS) 보고서를 따로 조회한다. 연결 미확보와 별도 기준을 표시하며 연결 기간/계정을 합산하거나 대체하지 않는다. 연결 기준 월간 추천 필터에는 별도 자료를 사용하지 않는다.

## 실행과 기록

- `tools/complete_financials.py`는 사용자가 요청한 일회성 재무 복구/보완 실행이다. 원문 재사용, 동일 PC 배타적 수집 잠금, 두 기업까지의 제한적 병행, 보고서별 간격과 기존 정상 파일 보존을 적용한다. OS 예약 등록이나 PC 간 자료 업로드는 없다.
- 진행/결과는 비공개 company-financials/completion-status.json, 검증 원문과 기업별 묶음은 같은 비공개 폴더에 저장한다. 대시보드 재무 모니터는 이 수집 진행 상태를 읽을 수 있다. 월간 추천 과거 버전은 재무 보완 때문에 자동 덮어쓰지 않는다.
- 거래소가 부여한 영숫자6자리 코드의 저장 재무도 종목/시장 일치 검증 후 읽는다. 숫자로만 이루어진 코드라는 기존 캐시 읽기 제한을 제거했다.
- 실제 공시 없는 기간·신규 상장/합병 이전 기간·원문 계정 해석/범위 불확실·비공개 원문은 구분해 남긴다. 배당/전체 차입금/상각비를 누락 값 대신 추정해 빈칸을 없애지 않는다.

## 근거와 검증

- 직접 읽은 출처: DART 기업 검색과 공개 연결·별도 재무제표 원문. 원문 URL/제출번호/기간/단위/해시는 각각의 저장 보고서에 보존한다. [DART 공식 재무 제공 범위](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS003).
- 단위검사는 가상 자료로 매출 중복/대차/순이익 귀속/연결·별도 분리/차입금 총계·리스 배제/누락 비대체/7% 정책을 확인한다. 실제 수집 범위·확보 결과·이번 실행한 검사와 남은 미확보는 PROJECT_STATE.md의 이번 실행 기록을 따른다.
