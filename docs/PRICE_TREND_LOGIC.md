# 가격 추세 화면의 계산 기준

2026-10-02 개선. 연결 화면은 완료 일봉으로 계산하며 최신 제공 가격을 별도 참고값으로 표시한다. 주문·자동매매 신호가 아니다.

## 기존 기본 가격 배열

종가 > 50일 > 150일 > 200일 단순평균, 현재 200일 평균이 20거래일 전보다 높음, 126거래일 수익률 양수, 같은 기간 시장 지수 초과수익 양수. 공개 가격 탐색에서는 거래대금이 미확보이므로 기존 검토 전략의 유동성 통과를 확정하지 않는다. 기존 탐색 필터·포트폴리오의 판단 기준은 이번 진단 화면 추가로 바꾸지 않았다.

## RS

[스탁이지 공개 설명](https://stockeasy.intellio.kr/guide/rs)의 최근 분기 2배 가중 아이디어를 참고한다. 63거래일로 나눈 독립 분기 수익률 네 개를 `(최근×2 + 이전 세 분기)/5`로 합산하고 같은 거래소의 저장 유효 기업에서 동률 중간 백분위를 계산한다. 253개 종목·지수 관측일 일치와 유효 비교기업 5개 이상이 필요하다. 전체 시장·공식 IBD·스탁이지 실제 RS와 동일하지 않다. 850억원 탐색 필터는 RS 모집단을 다시 계산하지 않는다.

## 개선한 8개 점검

[미너비니 측에서 공개한 교육 리뷰](https://cdn.minervini.com/static/dist/mtp-review.1f8e8633.pdf)의 이동평균·52주 범위·상대강도·VCP 관점을 참고한 연구용 변형이다. 저점 30%, 고점 25%, 자체 RS 70은 이 프로젝트의 명시적 기준이며 원전 SEPA 전체를 재현한다고 주장하지 않는다. 장중 고가·저가 대신 완료 종가 범위를 사용한다.

1. 종가가 150·200일선보다 높다.
2. 150일선이 200일선보다 높다.
3. 200일선이 21거래일 전보다 높다. 한 달간 매일 상승했음을 의미하지 않는다.
4. 50일선이 150·200일선보다 높다.
5. 종가가 50일선보다 높다.
6. 직전 52주 최저종가 대비 30% 이상 높다.
7. 직전 52주 최고종가 대비 하락률이 25% 이내다.
8. 위의 자체 RS가 70 이상이다.

모든 조건을 충족해야 통과한다. 필수값 미확보는 대기이고 알려진 조건 실패가 있으면 미충족이다. 거래정지·최근 거래 없음은 판정을 보류한다. 52주 범위는 해당 지수 관측일과 일치하는 연속 종목 일봉이 직전 52주 전체를 포함해야 제공한다.

스탁이지 공개 MMT의 다섯 조건도 별도 보완 정보로 표시한다. 공개식 `52주 고가 ≤ 종가×1.25`를 최고종가에 적용하며, 이 식은 최고종가에서 20% 이내 하락에 해당한다. 위의 25% 조건과 분모를 혼동하지 않는다. 원천·일수·종가 대체·모집단 차이가 있으므로 스탁이지 동일 결과라고 표시하지 않는다.

## 눌림과 돌파

- 돌파선: 오늘을 제외한 직전 20거래일 최고종가. 당일 고가 기준 피벗이나 미너비니의 차트 패턴 피벗과 다르다.
- 준비: 돌파선 아래 3% 이내. 선 위로 마감하면 가격 돌파를 표시하고, 당일 거래량 / 직전 50일 평균 거래량이 1.5배 이상이면 거래량 동반 상태를 구분한다.
- 되밀림: 전날 종가가 그 전 20일 최고종가를 넘었지만 오늘 종가가 그 고정 기준선 이하로 내려왔다.
- 수축 참고: 최근 30일을 앞선→최근 10일씩 나눈 종가 범위 `(최고/최저−1)×100`이 연속 감소하고, 최근 10일 / 60일 로그 수익률 표준편차 및 최근 5일 / 50일 평균 거래량이 각각 0.7 미만. 변동성이 0이면 비율을 대기한다. 이 숫자 조건은 VCP 확정 인식이 아니다.
- 거래량은 원천 제공값이며 가격과 세부 수정 방식이 일치한다는 보증이 없다. 거래대금은 가격×거래량으로 임의 대체하지 않는다.

## 차트와 성능

3·6·12개월은 최대 63·126·253 완료 관측일의 표시 범위다. 범위를 바꿔도 점검·이동평균 계산 기준은 달라지지 않는다. 종가·20/50/150/200일선, 돌파선과 거래량을 표시한다. 연결 화면의 상세 진단은 선택 기업 조회에서만 전송하므로 전체 기업 차트를 첫 화면에 다시 포함하지 않는다. 저장 재무자료와 개인 입력을 삭제하지 않는다.

사용자 선택 ③ 추세 중심 추천안 적용: 기본 종가 선과 원천 OHLC가 확인된 경우의 캔들 전환, 선별 표시, 돌파선 숨김, 날짜별 교차선과 거래량, 전체 이력 구간 손잡이 및 시작·끝 날짜 입력을 제공한다. 가격축은 만원, 값 확인은 원 단위다. 선 위의 커서 값은 보간값으로 명시하고 상단 날짜·종가는 가장 가까운 실제 관측값을 보여준다. 시가·고가·저가가 없거나 종가가 상세 이력과 일치하지 않으면 캔들을 만들지 않는다. 기업별 차트 설정은 탭 내 화면 전환과 자동 갱신 인계 시 유지한다. 외부 차트 라이브러리 요청 없이 자체 SVG로 표시한다.
