# 추세 분석용 가격·지수 이력

집 PC의 세 종목(삼성전자·SK하이닉스·현대차)에 대해 공개 Yahoo Finance 일별 시고저종·거래량과 KOSPI 지수의 저장본을 연결했다. 2026-09-23까지 공통 관측일 253개를 사용한다. 종목의 최근 20개 거래대금은 기존 인포맥스 저장본에서 날짜별로 연결했다. 앱 **추세 연구**에 출처·가격 차이와 결과를 표시한다.

원본 JSON은 로컬 `private_data/infomax/home-20260928/`에 저장한다. 각 파일의 심볼·한국 시간대·날짜 중복·유효값·분할 이벤트를 검사한다. 조회 범위에 분할 이벤트가 없어 이 범위의 시고저종을 분할 조정 기준으로 사용한다. Yahoo Finance의 배당까지 반영한 `Adj Close`는 사용하지 않는다. [Yahoo의 조정 종가 설명](https://help.yahoo.com/kb/SLN28256.html)에 따르면 그 값은 배당과 분할을 모두 조정한다. 공개 시세의 출처와 단위·수정 기준은 로컬 스냅샷에 남긴다.

Yahoo 종가와 인포맥스 종가는 최근 날짜에 차이가 있다. 겹치는 99개 관측 중 1원 초과 차이는 삼성전자 7개, SK하이닉스 9개, 현대차 8개였다. 최신일 차이도 종목별로 기록하고 화면에 표시한다. 기존 가격·수급·재무 수치는 Yahoo 자료로 교체하지 않는다. 이 추세 결과는 사용자 지정 KRX 기준의 **잠정 참고자료**이며 원자료 거래소·수정 기준을 독립적으로 인증한 것은 아니다.

일별 인포맥스 파일을 저장한 뒤 앱의 **저장 파일로 갱신**을 누르면, 이미 추세 자료가 연결된 PC에서 새 가격일에 한해 공개 시세를 다시 조회·검증한다. 종가 날짜가 맞지 않거나 조회가 실패하면 일별 인포맥스 자료는 보존하고 추세 판정은 `자료 부족`으로 둔다. 같은 버튼으로 재시도할 수 있다. 공개 응답은 PC 로컬 데이터 폴더의 `trend-source/<가격일>/`에 해시별로 남는다. 추세 점수는 이 세 종목 사이의 상대 순위다. 비교 대상이 세 개뿐이므로 점수와 일간 목록을 넓은 시장 순위로 해석하면 안 된다.

보관된 공개 JSON을 직접 다시 연결할 때:

```powershell
.\.venv\Scripts\python.exe tools/trend_history.py --base <기준스냅샷.json> --directory <저장된JSON폴더> --output <새스냅샷.json>
.\.venv\Scripts\python.exe batch.py import-file --profile <이PC프로필> --mode user_input --file <새스냅샷.json>
```

입력과 출력은 로컬에 보관하며 새 출력 이름을 사용한다. 일상 갱신은 앱 버튼을 사용한다. 예약 수집은 설정하지 않았다.
