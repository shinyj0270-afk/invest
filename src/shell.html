비교 기준

산업 분류와 자료 기준일은 입력 데이터가 정합니다. 금융업·지주사 등 사업구조가 다른 기업은 별도 비교 체계가 필요합니다. 이 시제품은 비금융 보통주용이며, 기업 간 우열을 하나의 점수로 단정하지 않습니다.

보유종목 직접 추가·수정

수량·매입가·현재가로 평가액과 손익을 계산합니다. 현금도 함께 반영합니다. 기업 검토에는 연구 근거를 추가해야 합니다.

현재가를 비워 두면 연결된 가격을 유지합니다. 수기 가격은 출처와 기준일을 남깁니다. 평가손익에는 세금·수수료·배당을 포함하지 않습니다.

구성 제약

아래 숫자는 개발용 가정입니다. 본인에게 적합하다고 검증된 투자 기준이 아닙니다.

확률·예상수익 최적화가 아니라 고정 슬롯 균등배분입니다. 빈 슬롯은 현금으로 남깁니다.

모형의 범위

후보는 입력 파일 안의 비금융 보통주만 사용합니다. 투자 논리·재무·가치평가 상태는 입력자가 검토한 분석값이며, 이 화면이 실제 공시에서 자동 추론한 결과가 아닙니다. 기존 조건검색과는 별도 입력을 사용합니다. 최신 로컬 앱에 연결하는 계약은 동봉된 v0.5 지시문에 있습니다.

종목코드와 공시 고유번호 매핑, 비금융·금융 구분, 산업 분류 버전을 검증해야 합니다.
현재 파일에 없는 기능
API 직접 수집, 실시간 시세, 자동 새로고침, 자연어 검색 해석, 외부 AI 호출, 주문·매매 실행은 구현하지 않았습니다.
데이터 처리 원칙
결측과 기준 혼합
없는 숫자는 null로 남깁니다. 스냅샷 안에서 가격일·재무기간·연결 기준·수급 기간·거래소 범위가 다른 행은 불러오기 단계에서 차단합니다. 실제 원문과 계산의 정확성까지 자동 검증하는 것은 아닙니다.
연결 정보 보호
API 키·비밀번호·계좌번호는 이 파일에 넣지 않습니다. 데이터 연결은 별도 로컬 수집기와 비밀정보 저장소에서 처리해야 합니다. 이 화면은 조회·분석 전용입니다.
산업별 특성
비금융 보통주를 기본 대상으로 합니다. 은행·보험·증권·리츠·스팩·우선주 및 지주사 전용 지표는 별도 확장 범위입니다.
사용 권한과 공개 범위
개인용으로 설계한 시제품입니다. 입력 데이터의 재배포·블로그 공개·외부 서버 배포 전에는 원천별 이용조건을 확인해야 합니다.
키움 REST API 공식 안내
지표 정의 · 수집기에 적용할 계약
이 화면은 아래 정의로 사전 계산된 metrics를 입력받습니다. 개별 재무 비율의 원자료 수집·정규화는 별도 구현이 필요합니다. 연간 이력의 영업이익률만 화면에서 직접 계산합니다.
